1. 계약의 성립과 적용 범위

이 계약은 PCssak Gongyu 0.1.0 얼리액세스 버전(이하 “프로그램”)의 설치와 사용에
적용됩니다. 설치 화면에서 이 계약을 확인하고 동의한 뒤 설치할 수 있습니다. 동의하지
않으면 설치하거나 사용하지 마십시오.

프로그램은 Windows 공유 폴더, 네트워크 드라이브, LAN 점검 및 사용자가 별도로 선택한
OpenSSH Server 구성을 돕습니다. 관리자 권한을 사용하는 기능은 실행 전에 별도 안내와
동의를 거칩니다. 구체적인 시스템 변경은 동봉된 `SECURITY.md`, 로컬 데이터 처리는
`PRIVACY.md`, 제3자 구성요소는 `THIRD-PARTY-NOTICES.txt`에 공개합니다.

2. 무료 얼리액세스 사용권

법적 제공자는 사용자가 이 계약을 지키는 조건으로 프로그램을 개인적 사용 또는 조직
내부의 합법적인 평가·업무에 설치하고 실행할 수 있는 비독점적 사용권을 부여합니다.
사용자는 프로그램을 실행할 PC와 네트워크를 관리하거나 적법한 관리 권한을 받아야 합니다.

이 버전은 무료 얼리액세스입니다. 프로그램은 결제 정보, 구독료, 라이선스 키 또는 온라인
활성화를 요구하지 않습니다. 얼리액세스 사용이 미래 유료 버전 구매나 자동 결제로 전환되지
않습니다. 향후 유료 버전은 가격과 조건을 별도로 공개하고 새 동의를 받아야 합니다.

3. 배포와 복제

백업을 위한 합리적인 복제는 허용됩니다. 프로그램을 다른 사람에게 제공할 때에는 파일을
변조하거나 이 계약과 제3자 고지를 제거하지 말아야 합니다. 공식 배포처가 아닌 곳에서 받은
파일은 무결성·업데이트·악성 변조 여부를 보장할 수 없으므로 공식 다운로드 링크 사용을
권장합니다.

프로그램 또는 PCSSAK 브랜드를 자신의 제품으로 오인시키거나, 악성 기능을 추가하거나,
불법 접근·감시·권한 침해에 이용해서는 안 됩니다. 관계 법령이 명시적으로 허용하는 범위와
오픈소스 구성요소가 별도로 부여한 권리는 이 조항으로 제한하지 않습니다.
MPL-2.0 적용 구성요소의 정확한 원본 소스 묶음은 설치 파일과 같은 `v0.1.0` 릴리스의
`PCssak-Gongyu-0.1.0-MPL-Sources.zip`으로 함께 제공합니다.
https://github.com/pcssakinc/pcssak-gongyu-releases/releases/download/v0.1.0/PCssak-Gongyu-0.1.0-MPL-Sources.zip

4. 사용자의 확인과 책임

프로그램은 사용자가 선택한 작업에 따라 방화벽 규칙, 서비스 시작 유형, 네트워크 프로필,
레지스트리, 로컬 계정, NTFS 접근 권한, 공유, 네트워크 자격증명 및 OpenSSH 선택적 기능을
변경할 수 있습니다. 사용자는 실행 전 화면의 대상·범위·위험 안내를 확인하고, 중요한 파일과
시스템 설정을 적절히 백업해야 합니다. 설치 후 보안·개인정보·제3자 고지 문서는
설치 경로의 `legal` 폴더에서 다시 확인할 수 있습니다.

타인의 PC, 계정, 공유 또는 네트워크에는 소유자나 관리자의 권한 없이 접근하거나 변경해서는
안 됩니다. 회사·학교 등 관리 환경에서는 조직 정책과 담당자 승인을 먼저 확인해야 합니다.

0.1.0의 SSH 기능은 호스트 PC가 같은 공유기·같은 온링크 LAN의 신뢰하는 물리 Ethernet 또는
Wi-Fi에 연결되고 Windows 네트워크 프로필이 Private 또는 Domain일 때만 지원합니다. 호스트의
TCP 22 규칙은 Windows의 실제 `sshd.exe`와 SSH를 켠 시점의 활성 로컬 IPv4 온링크 CIDR로
제한됩니다. Public 네트워크, VPN·터널, 인터넷 직접 접속과 라우터 포트포워딩은 지원하지
않습니다. 방화벽 범위를 모든 원격 주소로 넓히거나 TCP 22를 인터넷에 노출하지 마십시오.

프로그램의 “로컬 준비 완료” 표시는 호스트 내부의 서비스·방화벽·리스너 상태를 확인한
결과이며 다른 PC의 실제 SSH 로그인, 명령 실행 또는 SFTP 성공을 보증하지 않습니다. 첫
접속에서는 별도 경로로 서버 호스트 키 지문을 확인하고 접근 권한이 있는 계정만 사용하십시오.

5. 얼리액세스의 성격

얼리액세스 버전에는 알려지지 않은 결함, 기능 변경, 호환성 제한이 있을 수 있습니다.
중요 업무나 복구가 어려운 환경에서는 별도 시험 PC 또는 검증된 백업을 사용하십시오.
0.1.0에서 공개할 설치본은 Windows 11 Home·Pro x64와 Windows 10 22H2 Home·Pro x64를
목표로 합니다. Windows 10 x86은 별도 후보의 실기 검증과 해시 확인이 끝나기 전에는 배포하거나
지원한다고 표시하지 않습니다. Windows 10의 운영체제 지원 종료·ESU·LTSC 수명주기는 사용자가
별도로 확인해야 하며, 모든 제조사 장비·보안 제품·도메인 정책·언어팩 조합을 검증했다고
보증하지 않습니다.

프로그램은 자동 업데이트 기능을 포함하지 않습니다. 새 버전 설치 여부는 사용자가 결정하며,
중요한 계약 또는 개인정보 처리 변경이 있으면 새 문서와 동의를 제공합니다.

0.1.0 설치 파일에는 Windows Authenticode 서명과 분리 서명이 없습니다. 따라서 Windows가
“알 수 없는 게시자” 또는 Microsoft Defender SmartScreen 경고를 표시할 수 있습니다. 보안
기능을 끄거나 경고를 무조건 우회하지 말고, 공식 `v0.1.0` GitHub Release의 고정 파일명과
`SHA256SUMS.txt`의 SHA-256이 일치하는지 확인한 뒤 설치 여부를 결정하십시오.

6. 보증과 책임의 범위

프로그램은 무료 얼리액세스 상태로 제공됩니다. 법적 제공자는 확인된 결함을 성실히 알리고
합리적인 범위에서 개선하지만, 중단 없는 동작이나 모든 환경과의 호환성을 보장하지 않습니다.

이 계약의 어떤 내용도 적용 법률상 제한하거나 배제할 수 없는 소비자의 권리, 법적 제공자의
고의·중대한 과실에 따른 책임 또는 인적 손해에 대한 책임을 제한하지 않습니다. 사용자가
권한 없이 시스템을 변경하거나, 경고를 무시하거나, 비공식 변조본을 사용하여 발생한 손해는
구체적인 사실과 적용 법률에 따라 판단합니다.
