# Issue and Contribution Guidelines / 이슈·기여 원칙

This public release repository is for verified PCssak Gongyu binaries, release documentation,
support guidance and user feedback. The proprietary application source is maintained separately
in a private repository.

이 공개 배포 저장소는 검증된 PCssak Gongyu 설치 파일, 릴리스 문서, 지원 안내와 사용자 의견을
위한 곳입니다. 자체 애플리케이션 소스는 별도 비공개 저장소에서 관리합니다.

## Responsible reports

- Search existing Issues before opening a new report.
- Use the structured bug or feature form and describe one problem per Issue.
- Use synthetic names and remove personal, customer, credential, network and confidential data.
- Do not upload third-party source, binaries, documents, screenshots or other material unless you
  have permission to share it.
- Do not attach passwords, private keys, pairing codes, tokens, exact internal IP addresses, real
  usernames, share names, full paths, directory listings, customer files or raw logs.
- Do not publish exploitable security details. Follow [SECURITY.md](SECURITY.md).

## Documentation contributions

Small corrections to release documentation, safe reproduction instructions and user-facing
translations can be proposed through an Issue. A Pull Request should be opened only after PCSSAK
requests or agrees to that contribution. Do not replace the Korean authoritative EULA or Privacy
Policy with an unreviewed translation, and do not describe a translation as legally certified.

By submitting text that you created, you confirm that you have the right to provide it and allow
PCSSAK to reproduce, edit and distribute it as part of the project documentation. Third-party
materials remain under their own rights and licenses.

## 한국어

- 새 Issue를 만들기 전에 기존 내용을 검색합니다.
- 버그·기능 제안 양식을 사용하고 Issue 하나에는 문제 하나만 적습니다.
- 합성 이름을 사용하고 개인정보·고객 자료·자격증명·네트워크 정보·회사 비밀을 제거합니다.
- 공유 권한이 없는 제3자 소스·바이너리·문서·화면을 첨부하지 않습니다.
- 비밀번호·개인키·페어링 코드·토큰·정확한 내부 IP·실제 사용자명·공유명·전체 경로·폴더 목록·
  고객 파일·원본 로그를 공개하지 않습니다.
- 악용 가능한 보안 내용은 공개하지 말고 [SECURITY.md](SECURITY.md)를 따릅니다.

릴리스 문서의 작은 오류, 안전한 재현 안내와 사용자용 번역은 Issue로 제안할 수 있습니다.
Pull Request는 PCSSAK이 요청하거나 사전에 동의한 경우에만 만드세요. 국문 정본 EULA·개인정보
처리방침을 검토되지 않은 번역으로 교체하거나 번역을 법률 검토·인증된 문서로 표시하면 안 됩니다.

직접 작성한 텍스트를 제출하면 해당 내용을 제공할 권한이 있고 PCSSAK이 프로젝트 문서의 일부로
복제·편집·배포할 수 있도록 허용한다는 뜻입니다. 제3자 자료는 각 권리와 라이선스를 따릅니다.
