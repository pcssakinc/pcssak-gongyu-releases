# PCssak Gongyu 0.1.7 — 무료 Early Access

무료 Early Access `0.1.7`은 앱 잠금(6자리 PIN), 사용자 자료 폴더 공유, 외부 공유 등록 해제와
페어링 안내를 개선합니다. 이 노트만으로 게시·전체 환경 실기 완료를 의미하지 않으며 실제
공개 여부는 [버전 고정 릴리스](https://github.com/pcssakinc/pcssak-gongyu-releases/releases/tag/v0.1.7)로
확인하고 같은 태그의 기존 자산은 교체하지 않습니다.

## 추가·변경 범위

- 현재 사용자의 바탕화면·문서·다운로드 등 전용 하위 폴더 공유를 허용하고, 시스템 폴더·프로필
  전체·AppData와 연결 경로는 차단합니다. 폴더 선택 직후와 실행 직전에 실제 경로를 확인합니다.
- 일반 외부 Windows 공유를 「내 공유」에서 해제할 수 있습니다. 확인한 공유 등록만 제거하며
  원본 폴더·파일·권한·계정은 유지합니다. 해당 공유를 사용하던 연결은 끊깁니다.
- 네트워크 검색에서 상대를 선택하면 페어링 주소가 자동 입력됩니다. 비밀 코드는 상대가 전달한
  값을 입력하며, 만료 시 「내 공유 → 페어링 코드 발급」에서 재발급하도록 안내합니다.
- 잠금 재사용·복구 버튼 상태와 저장 파일 오류 처리를 개선했습니다. Windows CNG로 비밀번호를
  검증하며 읽기 실패·파일 손상을 잠금 해제로 처리하지 않습니다.
- 앱 잠금: 6자리 PIN을 설정하면 실행 시 잠금 화면이 먼저 뜹니다. PIN 원문은 저장하지 않고
  PBKDF2-HMAC-SHA256(600,000회)·무작위 솔트 검증값을 Windows DPAPI로 감싸 저장합니다.
  헤더 버튼 또는 `Ctrl+Shift+L` 즉시 잠금, 0·5·15·30분 자동 잠금, 4회 실패 뒤 30초부터
  최대 15분까지 늘어나는 대기 시간을 제공하며 잠금 중에는 백엔드가 명령을 거부합니다.
- PIN 분실 대비: 12자 1회용 복구 코드를 권장하고, 보조 수단으로 3개 질문 중 하나의 답을
  등록할 수 있습니다. 질문 방식은 추측·사회공학에 노출될 수 있어 위험을 명시하며 더 긴 대기
  시간을 적용합니다. 같은 Windows 계정으로 로그인한 사람은 막지 못하므로 `Win+L`을 함께 쓰세요.
- 중단된 작업 안내: 이전 작업의 중단 기록 때문에 자동 설정·SSH·공유가 막히면 원인과 해결
  경로를 안내하고 설정 탭의 「중단된 작업 수동 확인」 카드로 바로 이동합니다.
- 공유 만들기: 잘못된 이름·설명·폴더·민감 경로는 실행 중 OpenSSH의 공유 계정 보호 검사보다
  먼저 거부하고, 실제 계정을 만들기 직전에 공유 전용 계정의 SSH/SFTP 차단을 다시 확인합니다.
  일반 Windows 계정의 SSH 인증 허용 정책과 기존 호스트 키를 보존합니다. 공유 전용 계정 차단
  설정은 추가할 수 있으며 서버 재시작이 필요하면 동의를 구하고 기존 연결에 영향을 줄 수 있습니다.
  검증 완료된 SSH 준비 뒤 다음 단계의 변경 없는 오류는 불필요한 중단 기록을 남기지 않도록
  단계별로 처리합니다. 미검증 부분 변경은 계속 확인 필요 상태로 보존합니다.
- 0.1.6에서 0.1.7로 진행할 때 정확한 버전·소유 표식을 확인하는 업그레이드 분기를 추가했습니다.

## 설치와 앱 내 업데이트

- 설치 파일은 `PCssak-Gongyu-0.1.7-Windows-x64-Setup.exe`입니다.
- 법률 정본과 업데이트 공개키를 바꾸지 않습니다. 정상 법률 동의 기록이 남은 0.1.6 사용자는 앱에서 새 버전을 확인하고 다운로드·서명 검증·사용자 승인 후 업데이트할 수 있습니다.
- 0.1.3·0.1.4 또는 시험 설치된 0.1.5도 법률 동의 기록·정확한 버전·소유 표식을 검증합니다.
- 0.1.0에는 앱 내 업데이트가 없으므로 공식 설치본을 한 번 수동 설치해야 합니다. 0.1.1 사용자는 법률 정본 변경에 따른 새 동의가 필요할 수 있습니다.
- 0.1.0·0.1.1 제거기의 글자 없는 예/아니오 창은 그 버전 제거기 자체의 결함이며 0.1.2부터
  수정됐습니다. 그 창의 [아니오]는 Windows 설정 원복을 생략하고 앱 제거를 계속합니다.
  제거가 끝난 뒤 새 설치본을 실행하세요. 0.1.0 덮어 설치는 지원하지 않습니다.
- 설정을 교체 대상에서 제외하며 이전 제거기를 먼저 실행하지 않습니다. 전체 Windows 환경의
  업데이트·설정 보존 실기 행렬은 아직 미완료입니다.

## 보안과 미완료 범위

Windows Authenticode 게시자 서명이 없습니다. Tauri·Minisign 업데이트 서명은 무결성을
검증할 뿐 Windows 게시자 신뢰나 Smart App Control 실행 허용을 보증하지 않습니다.
앱은 SAC·Defender·SmartScreen·방화벽·조직 정책을 자동으로 해제하거나 우회하지 않습니다.
설치·일반 실행을 위해 보호 기능을 끄지 마세요. 확인된 미서명 제거기 SAC 차단의 제거 전용
조건부 안내는 [보안 정책](../SECURITY.md)을 따르며 재활성화가 불명확하면 끄지 않습니다.

- Windows 10/11 Home·Pro x64 전체 실제 설치·업데이트·복구·제거 행렬: 미완료.
- 앱 잠금·복구 코드·보안 질문·자동 잠금의 Windows 실기 검증: 미완료.
- 실제 두 PC SSH/SFTP·끄기·재설치 없는 재켜기·완전 원복·기존 세션 종료 여부 행렬: 미완료.
  자동 SSH 회귀검증에서 실패가 확인되면 공개를 중단합니다. 자동 검사·과거 버전의 한 PC
  실측을 이번 전체 행렬 성공으로 표시하지 않으며 전체 실기 행렬은 0.2.0 전 완료해야 합니다.
- Authenticode 게시자 서명·외부 법률 검토·독립 공급망 검토: 미완료.
- 최종 소스의 Windows 로컬 검증·양 업데이트 서명·정확한 9자산·SHA-256 검증: 공개 전 필수.
  이번 무료 Early Access는 승인된 실제 Windows 로컬 검증 경로를 사용하며 GitHub Actions를
  실행하지 않습니다. 로컬 대체는 `0.1.2 <= 버전 < 0.2.0`에서만 허용하며 실행하지 않거나
  실패한 Actions를 성공으로 표시하지 않습니다.

복구 가능한 시험 PC와 백업에서 실측하며 개인키·암호·PIN·복구 코드·계정·개인 경로·네트워크
주소·원본 로그를 공개 이슈에 올리지 마세요. 이 문서만을 검증·배포 완료 증거로 해석하지 않습니다.
