> 안내는 [README](../README.ko.md), [고객지원](../SUPPORT.md), [보안 정책](../SECURITY.md)을
> 우선합니다. 과거 버전의 제한이나 검증 상태를 현재 버전의 동작으로 해석하지 마세요.

[English](KNOWN-LIMITATIONS.md)

이 문서는 PCssak Gongyu 0.1.1 무료 Early Access의 공개 범위를 설명합니다. 실제 제공 여부는
버전 고정 [`v0.1.1` 릴리스](https://github.com/pcssakinc/pcssak-gongyu-releases/releases/tag/v0.1.1)와
그 페이지의 정확한 9개 자산으로만 판단합니다. 설치 파일이나 고정 자산이 하나라도 없다면
완료된 공식 0.1.1 배포가 아닙니다.

## Early Access와 설치 파일

- 0.1.1은 1.0 이전 버전이며 알려지지 않은 결함이나 변경되는 동작이 있을 수 있습니다.
- 공개 0.1.1은 Windows x64 NSIS per-machine 설치 파일 하나이며 관리자 승격이 필요합니다.
- x86 설치 파일은 게시하지 않습니다. i686 컴파일·시험은 지원 선언이 아닙니다.
- 설치 파일에는 Authenticode 서명이 없어 알 수 없는 게시자나 SmartScreen이 나타날 수 있습니다.
- SmartScreen, Microsoft Defender, 방화벽과 다른 보안 제품을 끄지 마세요.
- 공개 0.1.0에는 앱 내 업데이트가 없습니다. 기존 사용자는 공식 0.1.1 설치본을 이번 한 번
  수동 설치해야 하며, 0.1.1 이후부터 앱 안에서 서명된 업데이트를 사용할 수 있습니다.
- `latest.json`은 Tauri 전용 업데이트 매니페스트이고, 사람·홈페이지용 정보는
  `DOWNLOAD-METADATA.json`으로 분리됩니다. 두 업데이트 서명은 Windows 게시자 신원 서명과
  목적이 다릅니다.
- 설치 파일은 WebView2 다운로드 부트스트래퍼를 사용합니다. Runtime이 없는 PC에서는 설치 중
  Microsoft 다운로드가 필요할 수 있으며 이후 유지·업데이트는 Windows와 조직 정책을 따릅니다.

## Windows 호환성

- Windows 11 Home/Pro x64와 Windows 10 22H2 Home/Pro x64는 검증 목표이며 모든 에디션·
  빌드·장치의 실기 완료를 의미하지 않습니다.
- Windows 10 일반 지원은 종료됐습니다. PCSSAK 지원은 Microsoft 보안 업데이트, ESU 자격 또는
  LTSC 수명주기를 대신하지 않습니다.
- ARM64 네이티브, Windows S 모드, Windows Server, macOS와 Linux는 지원 배포 대상이 아닙니다.
- 도메인 GPO, 엔드포인트 보안, 사용자 방화벽과 선택적 기능 원본 정책이 정상 작업을 덮어쓰거나
  차단할 수 있습니다.
- 모든 하드웨어·언어팩·VPN·EDR·관리 네트워크 조합을 시험하지 않았습니다.

## 같은 LAN 범위

- 공유·매핑·페어링·SSH는 같은 신뢰 공유기와 LAN의 PC를 대상으로 합니다.
- SSH 호스트는 물리 Ethernet·Wi-Fi에서 Private 또는 Domain 프로필을 사용해야 합니다.
- 활성 Public 프로필, 주소가 있는 VPN·터널, 어댑터·방화벽 조회 실패가 하나라도 있으면 SSH
  켜기를 차단합니다.
- Public, VPN·터널, 인터넷 직접 접속과 라우터 포트포워딩은 지원하지 않습니다. TCP 22를
  인터넷에 노출하지 마세요.
- DHCP 주소나 물리 네트워크가 바뀌면 기록된 SSH 범위가 오래될 수 있습니다. SSH를 끄고 새
  LAN을 확인한 뒤 다시 켜세요.
- 라우팅 서브넷·VLAN·기업 방화벽 정책은 관리자의 검토가 필요할 수 있으며 앱이 자동으로
  범위를 넓히지 않습니다.

## SSH는 화면 공유 원격지원이 아닙니다

- SSH 설정·원격 셸·명령 실행·SFTP는 같은 LAN에서 사용하는 0.1.1 핵심 기능입니다.
- 화면 공유·마우스 제어용 MSRA는 비활성화되며 SSH로 몰래 제공되지 않습니다.
- “로컬 준비 완료”는 호스트 서비스·방화벽·리스너 확인이며 다른 PC의 로그인·파일 전송을
  증명하지 않습니다.
- 앱은 `%ProgramData%\ssh\sshd_config`를 수정하거나 키 전용 인증·`AllowUsers`·신뢰 호스트
  키 지문 배포·IP 허용 목록을 자동 구성하지 않습니다.
- 첫 접속은 별도 경로로 호스트 키 지문을 확인해야 하며 계정 인증·권한은 Windows와 OpenSSH
  정책을 따릅니다.
- 일반 「SSH 접속 끄기」는 OpenSSH Server를 제거하지 않습니다. PCSSAK 허용 규칙을 닫고 보호
  차단을 확인한 뒤 `sshd`를 중지·비활성화하며, 다음에는 재설치 없이 한 번에 다시 켤 수 있습니다.
- 별도 「SSH 환경 완전 원복」은 PCSSAK이 기록한 서비스·방화벽 변경을 복원하고 PCSSAK이 처음
  설치한 OpenSSH Server만 제거합니다. 사용자가 원래 설치한 기능은 제거하지 않습니다.

## SMB 공유·페어링·매핑

- Windows와 PCSSAK 기록의 소유권 증거가 모두 맞는 공유만 관리합니다. 외부·검증 불가 구버전
  공유는 파괴적 작업에서 읽기 전용입니다.
- 기존 공유를 자동으로 가져오지 않습니다. 이름·경로만 같아서는 소유권 증거가 아닙니다.
- 민감한 시스템·프로필 경로를 차단하지만 이 검사는 백업을 대신하지 않습니다.
- 페어링은 8자리·5분·1회용 코드를 사용합니다. 속도 제한이 온라인 추측을 줄이지만 없애지는
  않습니다. 코드가 화면·클립보드 기록·주변에 노출되지 않게 하세요.
- 최종 클라이언트 메시지 뒤 응답이 불확실하면 이전 코드를 재사용하지 말고 새 코드를 발급하세요.
- 드라이브 매핑과 Windows 자격 증명 관리자 상태는 Windows 사용자·승격 토큰·세션에 따라 다를
  수 있습니다. 충돌하는 기존 자격증명은 수동 확인이 필요할 수 있습니다.

## 원복과 제거

- 원복은 정상적인 소유권·변경 전 기록에 의존합니다. 증거가 없거나 충돌하면 추측해 삭제하지
  않고 거부합니다.
- 시작 유형을 복원해도 실행 중 서비스는 즉시 중지하지 않을 수 있습니다. 다른 Windows 기능이
  같은 서비스를 사용할 수 있기 때문입니다.
- 사용자가 만든 공유·매핑·Windows 자격증명·로컬 앱 데이터·WebView2 데이터·자동 시작과
  사용자가 원래 설치한 OpenSSH Server는 제거 뒤 남을 수 있습니다.
- 원복이 실패하면 복구 도구를 보존하기 위해 제거가 중단될 수 있습니다.
- 원복과 되돌리기는 안전 편의 기능이며 전체 시스템 백업이 아닙니다.

## 로컬 데이터와 개인정보

- 로그에는 IP·호스트명·공유명·경로·Windows 오류가 포함될 수 있습니다. 자동 업로드하지 않지만
  지원 요청 전 사용자가 제거해야 합니다.
- 로컬 JSON·DPAPI 자격증명·WebView2 저장소·저널은 사용자가 삭제할 때까지 남을 수 있습니다.
  중앙 수집하지 않은 데이터를 PCSSAK이 원격 삭제할 수 없습니다.
- 이메일·GitHub·Cloudflare·Google·Microsoft를 사용하면 각 서비스가 자체 방침에 따라 정보를
  처리합니다.
- 적용 법률이 허용하는 범위에서 국문 EULA와 개인정보 처리방침이 기준이며 영문은 참고
  번역입니다. 전 세계 법률 준수 인증을 주장하지 않습니다.

## 검증 경계

로컬 자동 시험·정적 검사·의존성 감사는 공개할 정확한 설치 파일 바이트의 실기를 대신하지
않습니다. 0.1.1은 법률 전문가 최종 외부 검토, Windows 10/11 Home·Pro x64 전체 VM·LAN 실기,
독립 공급망 승인과 GitHub Actions를 0.1.2로 유예했습니다. 이 유예를 호환성 또는 법률 검토
완료로 표시하면 안 되며, 릴리스 노트는 완료한 환경과 정확한 파일만 증거로 사용해야 합니다.
