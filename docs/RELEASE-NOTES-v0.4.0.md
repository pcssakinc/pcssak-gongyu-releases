# PCssak Gongyu 0.4.0 — Free Early Access 변경일기

일상적인 SSH 켜기·끄기는 정상으로 사용하고 있는데 과거 방화벽 기록의 조회와 복구가
오래 걸리거나 오류로 끝나는 경험을 바탕으로, 일반 SSH 화면과 설정을 정리했습니다.
0.4.0에서는 초보자가 자주 쓰는 조작을 먼저 보여 주고 과거 기록의 특수 복구 화면은
제품 화면에서 퇴역합니다. 기록을 지우거나 복구가 완료됐다고 처리하는 변경은 아닙니다.

## SSH 조작과 과거 복구 화면

- 일반 SSH 화면에는 켜기·끄기와 우리 SSH 설정 원복을 남깁니다.
- 「보관 대상 확인 / 다시 조회」와 「이전 방화벽 기록 복구」 버튼, 설정에서 이 화면으로
  이동하는 경로를 제거했습니다. 일반 조작 전에 구형 V4·V5 기록 복구를 자동 실행하던
  화면 경로도 제거했습니다.
- WebView에서 구형 타사 규칙 및 별도 식별 기록 복구의 조회·적용·취소 명령 다섯 개를
  호출할 수 없도록 권한을 줄였습니다. 개발 회귀시험의 내부 도우미는 유지합니다.
- 현재 LAN 규칙의 소유권, 설치 전 SSH 서비스 상태와 우리 설정 원복에 필요한 보호
  기록은 유지합니다. 정상적인 켜기·끄기와 원복의 검증을 생략하지 않습니다.

## 설정을 찾기 쉽게

언어, Windows 자동 실행, 테마, 업데이트와 앱 잠금은 설정 상단에 배치했습니다.
백업·복원과 저장한 로그인 정보는 「데이터 관리」, 시작 안내·로그·보안 안내는
「문제 해결」, 검색 성능·Early Access 범위·앱 정보는 「고급 설정」에서 펼쳐 볼 수
있습니다. 중단된 작업 안내는 접힌 영역 밖에 유지합니다.

백업과 로그인 정보의 설명을 짧게 다듬고, 다른 PC나 Windows 계정에서는 비밀번호를
다시 입력해야 할 수 있다는 제한을 유지했습니다. 복원 동의, 덮어쓰기와 삭제 확인의
기능은 유지합니다. 변경한 화면 안내는 지원하는 10개 언어에 반영했습니다.

저장한 로그인 정보의 오류 안내에 내부 오류 원문을 그대로 노출하지 않도록 정리하고,
「모두 삭제」는 첫 조회 단계부터 중복 실행을 막았습니다. 삭제 전 확인 절차는 유지합니다.

## 우리 SSH 설정 원복의 범위

0.3.9에서 도입한 보호된 부분 원복의 범위는 유지합니다. 독립적인 과거 타사 규칙
복구가 남은 상태에서 보호 기록과 대상의 비중첩을 확인하면, 앱 소유 허용 규칙과
설정을 정리하고 수신 서비스를 중지한 채 보호 차단을 유지할 수 있습니다.

이 결과는 **부분 원복**입니다. 과거 규칙의 원래 활성 상태 복원, 설치 전 서비스 시작
유형·실행 상태 복원, 앱이 설치한 OpenSSH 기능 제거, Public 프로필 복원과 보호 차단
해제는 보류될 수 있습니다. 손상된 기록, 현재 규칙과 겹치는 대상이나 읽을 수 없는
상태를 성공으로 바꾸지 않습니다. 남은 기록의 별도 복구가 0.4.0에서 해결됐다고
약속하지 않으며, 「우리 설정 정리」가 PC 전체의 설치 전 상태 복원을 뜻하지 않습니다.

## 설치와 업데이트

0.3.9의 법률 정본과 업데이트 공개키를 그대로 사용합니다. 0.3.9에서 정상 법률 동의
기록을 확인할 수 있으면 공식 0.4.0이 공개된 뒤 앱에서 다운로드·서명 검증·사용자
승인을 거쳐 업데이트할 수 있습니다. 0.3.8 이하 앱은 현행 공개키를 갖고 있지 않으므로
공식 설치본을 직접 내려받아 대화형으로 설치해야 합니다. 업데이트 자체가 SSH를
켜거나 과거 방화벽 복구를 완료하지는 않습니다. 중단 복구 도중 구버전 실행 파일로
강제 복귀하지 마세요.

- 설치 파일은 `PCssak-Gongyu-0.4.0-Windows-x64-Setup.exe`입니다.
- 법률 정본과 0.3.9의 업데이트 공개키를 바꾸지 않습니다. 정상 법률 동의 기록이 남은 0.3.9 사용자는 앱에서 새 버전을 확인하고 다운로드·서명 검증·사용자 승인 후 업데이트할 수 있습니다.
- 0.3.8 이하 사용자는 현행 업데이트 공개키가 없으므로 공식 0.4.0 설치본을 한 번 직접 내려받아 대화형으로 설치해야 합니다.
- 0.1.1~0.3.9 사용자는 기존 앱을 먼저 제거하거나 설정·공유 장부·SSH 설정·중단 기록을 지우지 않고 공식 설치본을 기존 설치 위에 보호 덮어 설치합니다.
- 0.1.0에는 앱 내 업데이트와 보호 덮어 설치를 지원하지 않으므로 구 버전을 제거한 뒤 공식 0.4.0 설치본을 직접 설치해야 합니다.
- 구형 앱에는 현행 공개키가 없어 서명 오류가 표시될 수 있습니다. 서명 검증을 우회하지 말고 공식 홈페이지나 버전 고정 GitHub 릴리스를 이용하며 설치본의 SHA-256을 공개 목록과 대조하세요.
- 버전 고정 MPL 원본: PCssak-Gongyu-0.4.0-MPL-Sources.zip
- Windows x86 설치본은 실제 Windows 10 x86 시험 전에는 공개하지 않습니다.

## 확인한 것과 아직 확인하지 못한 것

최종 고정 소스의 화면 시험, 정적 검사, x64·i686 Rust 시험과 설치본·업데이트 서명·
정확한 아홉 공개 자산의 결과는 해당 SHA의 최종 검증 기록으로 판정합니다. 코드 또는
모의 시험의 통과를 실제 Windows 설치나 SSH 동작의 성공으로 옮겨 적지 않습니다.

0.4.0 설치본의 실제 설치·업그레이드·제거, 재부팅 뒤 SSH 상태와 두 물리 PC의
SSH/SFTP·완전 원복 연속 실기는 **NOT_RUN**입니다. 기존 버전에서 한 PC의 켜기·
끄기를 사용했다는 경험을 이번 설치본의 실기 검증으로 간주하지 않습니다.
Windows 10/11 Home·Pro 전체 행렬, 외부 법률 검토, 독립 공급망 검토와 Windows
Authenticode 게시자 서명도 미완료입니다. 무료 Early Access의 실제 이용은 복구
가능한 시험 PC와 최신 백업에서 먼저 확인하고 보안 제품을 유지해 주세요.
Tauri와 별도 Minisign 업데이트 서명은 파일 무결성을 위한 것이며 Windows 게시자
신원 서명을 대신하지 않습니다.

- Windows Authenticode 게시자 서명이 없습니다. Windows가 실행을 막을 수 있습니다.
- Windows 10/11 Home·Pro 전체 실기 검증이 완료되지 않았습니다.
- 실제 두 PC의 SSH/SFTP 실기 검증이 완료되지 않았습니다.
- 외부 법률 검토가 완료되지 않았습니다.
- 독립 공급망 검토가 완료되지 않았습니다.
- 공개 자산의 Tauri 업데이트 서명, 별도 Minisign 서명과 SHA-256을 검증합니다.
  복구 가능한 시험 PC에서 사용하세요. 보안 프로그램을 끄지 마세요.
