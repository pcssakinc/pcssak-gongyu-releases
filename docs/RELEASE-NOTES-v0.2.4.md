# PCssak Gongyu 0.2.4 — 무료 Early Access

0.2.4는 SSH 켜기가 실패하고 그 실패가 남긴 중단 기록 때문에 자동설정까지 막히던
연쇄 결함의 **원인**을 고치는 패치입니다. 함께 진행 중인 작업을 안전하게 멈추는 기능,
사용자가 직접 확인할 수 없었던 중단 기록의 자동 점검, 화면 전반의 개편을 포함합니다.
코드 수정과 화면·메모리 재현을 실제 사용자 PC의 접속 성공과 구분하며, 오류 표시나
안전 검증을 삭제하지 않습니다.

## 스토어 앱 방화벽 규칙 오판 수정 (핵심 원인)

- Windows 스토어 앱(앱 컨테이너)의 수신 허용 규칙은 프로토콜이 `Any`이고 프로그램이
  비어 있어 TCP 22 후보로 분류될 수 있습니다. 실제로는 패키지 SID에 결속돼 비패키지
  프로세스인 `sshd.exe`에 적용되지 않으므로 감사 대상에서 제외해야 합니다.
- 이전 판별은 변경 가능한 정책 저장소(`PersistentStore`)만 조회했습니다. 스토어 앱의
  네트워크 격리 규칙은 `ConfigurableServiceStore`에 생성되므로 대응을 찾지 못했고,
  그 결과 Windows 기본 규칙 수십 건이 "안전 판정 불가"로 남아 SSH 켜기가 차단됐습니다.
- 이제 그룹 정책을 포함한 유효 정책(`ActiveStore`)과 앱 저장소의 패키지 결속을 함께 읽습니다.
  COM으로 관측한 같은 이름의 규칙 개수·활성 상태·프로그램이 모두 대응하고, 모든 규칙이
  프로그램 없는 패키지 전용일 때만 제외합니다. 대응되지 않거나 판독할 수 없는 규칙은
  기존의 보수적 판정을 유지합니다. 표시 이름으로 예외를 만들지 않습니다.
- 본체와 프로그램 필터를 각각 한 번만 열거해 후보 개수와 무관하게 저장소별 조회 2회로
  판정합니다. 규칙이 많은 PC에서 상태 조회가 멈춘 것처럼 보이던 원인도 함께 줄어듭니다.
- 규칙 1건마다 경고 한 줄을 남기던 로그를 집계 한 줄과 상한 있는 표본으로 바꾸고,
  판별에 필요한 프로토콜·포트를 함께 기록합니다. 같은 조회에서 규칙마다 반복되던 경고를 줄입니다.

## 변경 전 사전 점검과 임시 비활성화 상한

- 보호 차단 규칙 생성·수명주기 기준선 기록·OpenSSH 설치보다 **먼저** 외부 허용 규칙의
  충돌 규모를 읽기 전용으로 확인합니다. 공용 물리 LAN에서는 필요한 신뢰 동의와 프로필
  전환 뒤 점검하며, 상한을 넘으면 SSH 변경을 시작하지 않고 전환한 네트워크의 원복을 시도합니다.
  원복이 검증되지 않으면 실패와 복구 기록을 유지합니다.
- 이전에는 변경을 시작한 뒤에 충돌을 다뤄서, 판별이 어긋나면 중단 기록이 남고 이후
  모든 변경이 차단됐습니다. 새 순서는 충돌 규모를 판정하기 전에 SSH 설치와 서비스·방화벽
  변경을 시작하지 않도록 합니다.
- 임시 비활성화 대상이 상한을 넘으면 쓰기 직전에도 거부합니다. Windows 기본 규칙
  수십 개를 한꺼번에 끄는 경로를 두 단계로 차단합니다.
- 켜기를 막는 기존 규칙의 개수와 이름 표본을 SSH 카드에 표시합니다. 규칙 이름은 이 PC
  화면과 로컬 로그에만 남고 외부로 전송되지 않습니다.

## 이미 되어 있으면 바꾸지 않습니다 (재실행 멱등)

- 자동 설정은 누르기 전에 현재 상태를 읽기 전용으로 확인합니다. 설정 마커·Public 네트워크
  없음·서비스·레지스트리·방화벽 세 축 전부 통과·445 수신이 모두 충족되면 작업 잠금을 잡지
  않고 「이미 적용되어 있습니다」로 끝냅니다. 어떤 Windows 설정도 바꾸지 않습니다.
- 하나라도 어긋나면 기존 적용 절차가 그대로 실행되며, 그 안에서도 항목별로 **부족한 것만**
  적용합니다. 값이 같은 레지스트리는 쓰지 않고, 계약과 완전히 같은 방화벽 규칙은 제거·재생성
  하지 않으며, 이미 자동 시작·실행 중인 서비스는 시작 유형을 다시 쓰지 않습니다.
- 방화벽은 이름과 켜짐 표시만으로 일치 판정하지 않습니다. 포트·서비스·프로그램·패키지·
  인터페이스와 추가 제한까지 모두 읽어 계약과 대조합니다. 읽지 못하거나 다른 제한이 있으면
  「이미 적용」이나 중단 기록의 자동 해제를 허용하지 않습니다.
- 같은 값을 다시 쓰는 일도 정책·권한·잠금 때문에 실패할 수 있습니다. 바꿀 것이 없을 때
  시작하지 않는 편이 더 안정적이고, 불필요한 중단 기록도 남지 않습니다.
- SSH 켜기도 같습니다. 서비스 실행·자동 시작·수명주기 기준선·보호 차단 없음을 먼저 값싸게
  확인하고, 통과할 때만 방화벽 계약·22번 포트 소유·거부 설정 근거까지 읽어 목표 상태면
  설치·서비스 재시작·규칙 재등록을 모두 건너뜁니다.
- 이 판정은 네트워크 프로필 전환보다 **앞에** 있습니다. 상태를 확인하려고 누른 클릭에서
  공용→개인 전환이나 장부 기록이 먼저 일어나지 않습니다.
- 이미 켜져 있으면 관리자 권한 요청과 동의 창도 나오지 않습니다. 상태 판독이 오래 걸리는
  PC에서는 화면 캐시를 신뢰하지 않고 정상 경로로 내려가며, 그때도 결과에 실린 「변경 없음」
  표시로 "켰습니다"가 아니라 "이미 켜져 있어 바꾸지 않았습니다"를 보여줍니다.
- 업데이트는 설정 기록을 지우지 않습니다. 기록은 `HKLM\SOFTWARE\PCSSAK\Gongyu` 에 있고
  설치기가 정리하는 키는 이와 다른 경로입니다. 업데이트 이후에도 실제 현재 상태를 다시
  점검하므로, 외부 정책·서비스·네트워크 변경이나 새 점검 항목 때문에 부족한 상태가
  표시될 수 있습니다. 이때도 부족한 항목만 적용합니다.

## SSH 작업의 안전 중지

- 켜기·끄기·완전 원복이 진행되는 동안 「안전하게 중지」를 제공합니다. 요청은 신호만
  전달하며 작업을 강제로 끊지 않습니다.
- 작업은 스스로 정한 안전 지점에서만 멈추고, 이미 바꾼 항목을 기존의 검증된 실패 원복
  경로로 되돌립니다. 되돌림까지 검증된 경우에만 "취소"로 기록해 중단 기록을 남기지 않습니다.
- 원복을 검증하지 못하면 취소로 표시하지 않고 기존 중단 복구 계약을 그대로 따릅니다.
- OpenSSH 설치(DISM) 구간은 중간에 끊지 않습니다. 설치가 끝난 다음 지점에서 사용자
  의사를 반영하며, 이 사실을 화면에 그대로 안내합니다.
- 마지막 검증 단계에 들어간 작업은 그대로 완료될 수 있습니다. 중지를 눌렀다는 사실만
  표시하고 완료·복구·접속 성공을 앞당겨 표시하지 않습니다.
- 중지 신호와 진행 표시는 매 실행의 식별자에 연결합니다. 중단 작업을 재개해도 이전 실행의
  늦은 중지 요청이나 응답이 새 실행을 취소하거나 결과를 덮지 않도록 합니다.

## 중단 기록 자동 점검

- 이전에는 사용자가 "실제 Windows 상태를 확인했다"고 선언해야만 차단이 풀렸습니다.
  일반 사용자가 서비스·방화벽·레지스트리를 대조할 방법은 없습니다.
- 이제 앱이 같은 판정을 읽기 전용으로 수행합니다. **완전히 꺼진 상태**(관리 허용 규칙
  흔적·외부 규칙 원복 기록이 없고 수신 서비스도 꺼짐) 또는 **계약대로 완료된 상태**만
  자동으로 해제합니다.
- 다른 프로그램의 규칙을 되돌릴 기록이 남아 있거나 보호 차단이 예상과 다르거나 일부만
  적용된 상태는 자동 해제하지 않고 기존 수동 확인·전용 복구 경로를 유지합니다.
- 손상된 기준선과 미완료 네트워크 원복 기록도 자동 해제하지 않습니다. 실제 상태 점검과
  기록 해제를 같은 작업 잠금 안에서 처리하고, 화면에서도 해제 후 최신 상태를 다시 읽습니다.
- 자동설정은 중단 기록으로 막히면 이 점검을 먼저 시도하고, 실제로 차단이 풀린 경우에만
  같은 작업을 한 번 이어서 실행합니다. 재시도는 1회로 제한합니다.
- 중단 기록에 그 기록을 남긴 제품 버전을 함께 보관해 화면에 표시합니다. 재설치·업데이트
  뒤 남은 기록이 어느 버전에서 왔는지 확인할 수 있습니다. 기존 기록에는 값이 없으므로
  "알 수 없음"으로 표시하며 이전 버전이 같은 파일을 계속 읽을 수 있습니다.

## 화면 개편

- 헤더·사이드바·카드·버튼·상태·진행률·단계 목록의 표면을 새로 정의했습니다. 4개 테마
  프리셋과 사용자 지정 색은 기존 파생 공식을 그대로 따라가고 본문 16px·버튼 44px 같은
  접근성 계약도 유지합니다.
- 키보드 초점 링을 추가하고, 활성 탭과 위험 동작을 색만이 아니라 표시선·테두리로 함께
  구분합니다. 모션 감소 설정에서는 전환 효과를 끕니다.
- 「안전하게 중지」 안내는 중지 버튼이 있는 동안에만 표시됩니다. 숨김 처리가 화면 규칙에
  가려지던 문제를 고쳐, 진행 중이 아닐 때 중지 설명만 남지 않습니다.
- SSH 켜기에 단계 목록과 경과 시간을 표시합니다. 어떤 단계가 오래 걸리는지 보이며,
  설치 단계는 Windows 속도에 따라 달라진다는 사실을 그 자리에서 안내합니다.
- 중단 복구 카드는 자동 점검을 1순위 동선으로 두고, 종류에 맞는 SSH 재개 버튼과 수동
  확인을 그 아래에 유지합니다.
- 자동설정·검색·중지의 중복 클릭과 앱 잠금 전 응답을 차단합니다. Guest 접근이나 빈 암호를
  권하던 오래된 안내를 10개 언어에서 현재의 인증·보안 정책에 맞춰 정정했습니다.
- 원격 데스크톱 실행은 Windows가 제공하는 시스템 폴더의 실행 파일로 고정했습니다.

## 설치와 앱 내 업데이트

- 설치 파일은 `PCssak-Gongyu-0.2.4-Windows-x64-Setup.exe`입니다.
- 법률 정본과 업데이트 공개키를 바꾸지 않습니다. 정상 법률 동의 기록이 남은 0.2.3
  사용자는 앱에서 새 버전을 확인하고 다운로드·서명 검증·사용자 승인 후 업데이트할 수 있습니다.
- 정상 법률 동의 기록이 있는 0.2.0·0.2.1·0.2.2도 동일한 검증·사용자 승인 절차로 앱 내
  업데이트할 수 있습니다.
- 0.1.9는 현행 법률 문서 확인을 위해 공식 설치본을 직접 실행합니다. 0.1.8 이하는 앞서
  고지한 업데이트 공개키 전환 때문에 공식 설치본을 한 번 직접 실행해야 합니다.
- 0.1.1~0.2.3은 먼저 제거하지 않습니다. 새 설치기가 기존 앱 파일을 보호 교체하며 사용자
  설정·법률 동의·공유 장부·SSH 복구 기록을 보존합니다. 0.2.3 허용을 이전 파일 백업,
  중단된 설치 복구, 대화형 교체, 재설치의 네 진입 분기에 추가했습니다.
- 0.1.0에는 앱 내 업데이트가 없으므로 공식 설치본을 한 번 수동 설치해야 합니다.
- 이미 제거했다면 새 공식 설치본을 사용하되 Windows 복구 기록을 임의로 지우지 마세요.
  앱 교체와 SSH 초기화는 다릅니다. 0.1.0만 별도 수동 제거 후 설치 대상이며, 새 동의가
  필요하거나 설치 기록이 손상됐다면 대화형 설치로 안내합니다.

## 안전·지원 및 검증 범위

공개 설치본은 Windows x64 전용입니다. SSH는 신뢰하는 같은 물리 LAN용이며 VPN·가상
어댑터를 신뢰 범위에서 제외합니다. 관리자 권한과 공용 물리 LAN 신뢰의 필요한 동의를
유지합니다. 카페·호텔·공항·게스트 Wi-Fi를 신뢰 LAN으로 전환하지 마세요.

기존 OpenSSH를 재사용합니다. 켜기는 서비스 실행·자동 시작을 함께 확인하고, 끄기는
서비스 중지·사용 안 함 시작 유형·보호 규칙을 확인합니다. 완전 원복은 별도 기능이며
앱이 직접 설치한 소유 증거가 있는 OpenSSH만 제거 대상입니다. 사용자 설정·외부 규칙을
일괄 삭제하거나 방화벽·보안 제품·조직 정책을 해제하는 방식은 사용하지 않습니다.

외부 허용 규칙이 상한을 넘는 PC에서는 SSH 켜기가 진행되지 않습니다. 이는 결함이 아니라
Windows 기본 규칙을 대량으로 변경하지 않기 위한 의도된 실패 폐쇄입니다. 화면에 표시되는
규칙 목록을 확인한 뒤 사용자가 직접 정리하거나 그 PC에서 SSH를 사용하지 않는 선택을
