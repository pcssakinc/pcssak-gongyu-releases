# PCssak Gongyu 0.1.9 — 무료 Early Access

0.1.9는 SSH 방화벽 스냅샷 비교와 개인·팀 공유, 관리자 재개 및 중단 복구를 개선합니다.
실제 제공 여부는 [버전 고정 공식 릴리스](https://github.com/pcssakinc/pcssak-gongyu-releases/releases/tag/v0.1.9)의
검증된 자산으로 확인합니다. 이 문서만으로 게시 또는 모든 환경의 실측 완료를 뜻하지 않습니다.

## 설치와 앱 내 업데이트

- 설치 파일은 `PCssak-Gongyu-0.1.9-Windows-x64-Setup.exe`입니다.
- 업데이트 서명키 전환으로 0.1.8 이하 사용자는 공식 0.1.9 설치본을 한 번 수동 설치해야 합니다.
- 0.1.1~0.1.8 사용자는 기존 앱을 먼저 제거하거나 설정·공유 장부·SSH 설정·중단 기록을 지우지
  않고 덮어 설치해야 합니다.
- 0.1.0에는 앱 내 업데이트와 덮어 설치를 지원하지 않으므로 구 버전을 제거한 뒤 공식 0.1.9
  설치본을 직접 설치해야 합니다.
- 이번 법률 정본은 바꾸지 않습니다. 0.1.9부터 새 키로 서명한 후속 업데이트를 앱에서 확인하고
  다운로드·서명 검증·사용자 승인 후 설치할 수 있습니다.
- 구형 앱에는 새 공개키가 없어 일반 서명 오류가 표시될 수 있습니다. 공식 릴리스 또는 공식
  홈페이지에서 직접 다운로드하세요. 서명 검증을 우회하지 마세요.

설치는 앱을 교체하며 기존 시스템 문제를 자동 수리한 것으로 표시하지 않습니다. 남은 중단은
새 앱에서 안내하는 해당 복구를 이어갑니다. 0.1.0의 제거 절차를 0.1.1~0.1.8 사용자에게
적용하지 마세요. 기존 법률 동의가 없거나 이후 정본이 바뀌면 대화형 설치와 동의가 필요할 수 있습니다.

과거 버전의 불변 태그·설치본·서명은 교체하지 않습니다. 설치 손상·보안 제품 차단 등 별도
문제의 해결이나 모든 PC의 설치 성공을 보장하지 않습니다.

## SSH 개선

- 방화벽 규칙은 대소문자·주소 목록 순서·IPv4 마스크 표기가 달라도 의미가 같으면 같은
  스냅샷 그룹으로 비교합니다. 서로 다른 범위·프로필·프로그램·원래 활성 상태는 합치지 않으며,
  원래 규칙 원문·정확한 개수·쓰기 전 기록·실패 시 복원 검증을 유지합니다.
- 이 불일치는 SSH 켜기의 방화벽 기록 단계에서 오류를 일으킬 수 있었습니다. 제보 사진과
  같은 시점의 원래 PC 로그가 없어 사진 속 오류 원인을 이것 하나로 확정하지는 않습니다.
- 켜기는 서비스 실행과 자동 시작(`Auto`)을 확인하고, 끄기는 중지와 시작 사용 안 함
  (`Disabled`)을 확인합니다. 재부팅 뒤에도 선택한 시작 정책을 유지하도록 설정하지만 실제
  재부팅 시험 완료를 뜻하지 않으며 조직 정책·외부 관리 도구가 값을 변경할 수 있습니다.
- 일반 끄기는 OpenSSH 기능을 제거하지 않아 다음 켜기에서 재설치하지 않습니다. 완전 원복은
  별도 동의 후 적용 전 상태를 복원하며, 앱이 설치했다는 소유 증거가 있는 기능만 제거합니다.
- 중단 복구는 원래 작업과 정확한 대상을 확인하고 최종 검증 성공 때만 완료합니다. 공유 준비나
  원복과 SSH가 얽힌 중단도 안내에 따라 명시적으로 SSH를 끄고 원래 복구를 이어가도록 합니다.
  기록을 무조건 삭제하거나 불확실한 상태를 성공으로 표시하지 않습니다.

## 공유·회원·관리자 재개

- 새 폴더 공유에서 개인·팀 방식을 선택하고 요청을 승인하며 회원별 폴더 권한을 관리합니다.
  기존 일반 Windows 공유와 구형 앱 공유를 새 회원 방식으로 자동 변환하지 않습니다.
- 필요한 SMB 서비스·방화벽과 정확한 물리 LAN을 확인하여 공유를 준비합니다. 공용 물리 LAN은
  사용자가 신뢰를 확인한 정확한 네트워크만 전환하며, 조직 정책이나 불명확한 연결을 우회하지 않습니다.
- 공유 입력은 일회용으로 암호화해 관리자 재실행에 전달합니다. UAC 취소 시 기존 초대·서비스·
  방화벽을 정리하지 않으며, 잠금 뒤 늦게 도착한 응답이나 오래된 입력을 실행하지 않도록 확인합니다.
- 선택한 공유·회원·권한과 원래 작업 기록을 결속해 중단 복구 범위를 제한합니다. 다른 회원의
  권한과 원본 폴더·파일은 삭제 대상이 아닙니다. 회원 연결을 종료하는 정리는 별도 동의를 받습니다.
- 공유 네트워크 원복 전에는 새·구형 기록 모두에서 SSH 의존성을 확인합니다. 실행 중이거나
  다시 시작될 수 있는 SSH의 LAN을 임의로 Public으로 바꾸지 않고 먼저 안전한 끄기를 안내합니다.
- 잠깐 연결을 끊는 동작과 저장 연결 등록 해지를 구분합니다. 저장된 연결의 재사용도 실제
  계정·권한·자격증명 상태를 검증하며 다른 PC의 드라이브 연결 완료로 오인하지 않습니다.

## 보안과 지원 범위

공개 설치본은 Windows x64 전용입니다. x86 컴파일·시험은 x86 공개 지원의 실기 증거가 아닙니다.
SSH는 신뢰하는 같은 물리 LAN용이며 VPN·가상 어댑터는 SSH 신뢰 범위에서 제외합니다.
VPN 경유 SSH·인터넷 직접 노출·포트 포워딩을 지원한다고 표시하지 않습니다. 공용 LAN 신뢰와
관리자 권한은 필요한 동의를 계속 요구합니다. 카페·호텔·공항·게스트 Wi-Fi에서는 신뢰 전환에
동의하지 마세요. 최초 OpenSSH 설치 시간은 Windows Update·WSUS·조직 정책에 따라 달라집니다.

Windows Authenticode 게시자 서명이 없습니다. Tauri 업데이트 서명·Minisign 서명·SHA-256은
파일 무결성을 검증하지만 Windows 게시자 신뢰를 대신하지 않습니다. Windows·보안 제품은
실행을 막을 수 있습니다. SmartScreen·Smart App Control·백신 경고나 조직 정책을 우회하지 마세요.
Defender·백신 등 보안 프로그램을 끄지 마세요. 해시·서명이 다르면 실행하지 마세요.

## 미완료 실측 고지

`0.1.2 <= 버전 < 0.2.0`은 실측을 수집하는 무료 Early Access입니다.

- Windows 10/11 Home·Pro 전체 실기 검증이 완료되지 않았습니다.
- 실제 두 PC의 SSH/SFTP 실기 검증이 완료되지 않았습니다.
- 외부 법률 검토가 완료되지 않았습니다.
- 독립 공급망 검토가 완료되지 않았습니다.
- 이번 후보의 실제 사용자 OS 설정 변경·설치·재부팅·두 PC 공유 연결은 미실행입니다.

복구 가능한 시험 PC에서 최신 백업과 함께 사용하세요. 순수 시험·컴파일·읽기 전용 점검은
실제 설치·SSH 로그인·SFTP·재부팅 지속성 시험을 대신하지 않습니다. 최종 소스의 승인된
Windows 로컬 검증 또는 Actions, 불변 9자산·두 업데이트 서명·MPL 원본·법률 정본 결속은
공개 전 필수입니다. 실행하지 않은 Actions를 성공으로 표시하지 않으며, 전체 실측과 신뢰
게시자 서명은 0.2.0 정식 단계 전에 보완해야 합니다.
