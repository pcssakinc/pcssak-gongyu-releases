## 2026-09-15 — 공개 0.3.2 SSH 실기 실패 확인·홈페이지 전환 보류

21:02 KST 사용자 실기에서 기존 SSH 설치 인식 뒤 방화벽 규칙 처리 84%가
`native_method_output_null`, `HRESULT=0`으로 실패했다. 실패 후 원복 검증은 완료되지
않았으며 다시 켜기는 2%에서 `LEGACY-RECOVERY`로 중단됐다. 제출된 실제 로그와
통합 담당자가 보존한 로컬 근거를 대조한 보고에 따라 현재 알려진 문제로 기록한다.
HRESULT 0을 작업·원복 성공으로 해석하지 않으며 상세 원인·수정 후 실기 성공은 미확정이다.

조사·수정 중이며 자동 시험·서명·공개 자산 판독의 통과와 실제 PC 해결 여부를 구분한다.
같은 증상의 반복 실행을 멈추고 앱·설정·복구 장부를 보존하도록 한영 README와 SUPPORT에
고지했다. 장부 삭제·방화벽 수동 초기화·보안 해제로 우회하도록 안내하지 않는다.

GitHub의 기존 0.3.2 불변 릴리스·태그·9자산·승인 노트는 교체하지 않았다. 홈페이지의
0.3.2 후보는 로컬에서 보존하고 push·PR·운영 전환을 보류했으며 운영은 0.2.8을 유지한다.
이는 0.2.8 재설치나 버전 하향을 해결책으로 권하는 내용이 아니다. 현재 이 기록은
실패 고지 문서 작업이며 새 수정판·실기 복구·홈페이지 배포 완료가 아니다.

[새 알려진 문제 일지](../WORKLOG_2026-09-15_V0.3.2_SSH_KNOWN_ISSUE.md)에 범위와
검증·미확인을 기록한다. 아래 공개 마감의 미실기 문장은 당시 시점의 기록으로 보존하며,
