# PCssak Gongyu 0.1.6 — 무료 Early Access

무료 Early Access `0.1.6`은 기존 Microsoft OpenSSH 재사용과 원복 정보 결속을 수정합니다.
승인된 회사 시험 PC에서 실제 켜기·끄기·재켜기·원복을 확인했습니다. 다른 PC에서의 로그인·
파일 전송과 전체 Windows 환경 검증은 별도이며, 이 노트만으로 게시 완료를 의미하지 않습니다.
실제 공개 여부는 [버전 고정 릴리스](https://github.com/pcssakinc/pcssak-gongyu-releases/releases/tag/v0.1.6)로
확인하며 같은 태그의 기존 자산은 교체하지 않습니다.

## 확인한 사실과 후속 수정

- 회사 시험 PC의 0.1.3→0.1.5 업데이트는 약 10.06초, 종료 코드 0으로 성공했습니다.
  설치 버전·제품 파일 해시·제거 등록과 사용자가 실행한 한국어 0.1.5 화면을 확인했습니다.
- 이후 SSH 켜기는 Microsoft가 서명한 기존 OpenSSH 별도 설치의 경로·신원 확인에서 중단됐습니다.
  이 결함 때문에 0.1.5는 공개하지 않았고 Latest는 0.1.3을 유지합니다. 과거 불변 자산은 보존합니다.
- 0.1.6은 기존 공식 서버의 신원·설정·방화벽 경로와 원복 정보가 같은 대상을 가리키도록
  수정하고 실제 원인을 구분해 안내하기 위한 버전입니다. 임의 경로 허용이나 보안 검사 해제가 아닙니다.
- 회사 PC의 0.1.5 설치 성공은 0.1.6 설치 성공을 의미하지 않습니다. 0.1.5 업데이트 뒤 앱 설정
  전체 파일의 바이트 비교와 전체 Windows·두 PC SSH 행렬은 미완료입니다. 아래 SSH 설정·키
  원복 비교는 별도의 승인된 전환 시험 결과입니다.
- 기존 Microsoft 별도 서버에서 실제 켜기·끄기·재켜기·원복이 모두 성공했습니다. 끄기 후
  IPv4/IPv6 수신 포트 닫힘·설치 유지와 원복 후 설정·호스트 키·원래 서비스 상태 보존을
  확인했습니다. 끄기의 완료 판정은 서비스·방화벽 목표 상태 확인이며 기존 SSH
  세션 전체의 종료를 별도로 검증하지 않습니다. 서비스 중지만으로 모든 기존 연결이 종료되는
  것은 아닙니다. [OpenSSH 프로젝트 설명](https://github.com/PowerShell/Win32-OpenSSH/issues/1681)

## 설치와 앱 내 업데이트

- 설치 파일은 `PCssak-Gongyu-0.1.6-Windows-x64-Setup.exe`입니다.
- 법률 정본과 업데이트 공개키를 바꾸지 않습니다. 정상 법률 동의 기록이 남은 0.1.3 사용자는
  앱에서 새 버전을 확인하고 다운로드·서명 검증·사용자 승인 후 업데이트할 수 있습니다.
- 0.1.4 또는 시험 설치된 0.1.5도 법률 동의 기록·정확한 버전·소유 표식을 검증합니다.
- 0.1.0에는 앱 내 업데이트가 없으므로 공식 설치본을 한 번 수동 설치해야 합니다.
  0.1.1 사용자는 변경된 법률 문서에 새 동의가 필요할 수 있습니다.
- 설정을 교체 대상에서 제외하며 이전 제거기를 먼저 실행하지 않습니다. 0.1.6의 실제
  업데이트·설정 보존 성공은 아직 검증하지 않았습니다. 공개 전에는 새 업데이트가 제공되지 않습니다.

## 보안과 미완료 범위

Windows Authenticode 게시자 서명이 없습니다. Tauri·Minisign 업데이트 서명은 무결성을
검증할 뿐 Windows 게시자 신뢰나 Smart App Control 실행 허용을 보증하지 않습니다.
앱은 SAC·Defender·SmartScreen·방화벽·조직 정책을 자동으로 해제하거나 우회하지 않습니다.
설치·일반 실행을 위해 보호 기능을 끄지 마세요. 확인된 미서명 제거기 SAC 차단의 제거 전용
조건부 안내는 [보안 정책](../SECURITY.md)을 따르며 재활성화가 불명확하면 끄지 않습니다.

- Windows 10/11 Home·Pro x64 전체 실제 설치·업데이트·복구·제거 행렬: 미완료.
- 실제 두 PC SSH/SFTP·끄기·재설치 없는 재켜기·완전 원복·VPN 공존 행렬: 미완료.
- Authenticode 게시자 서명·외부 법률 검토·독립 공급망 검토: 미완료.
- 최종 소스 Actions·양 업데이트 서명·정확한 9자산·SHA-256 검증: 공개 전 필수.

복구 가능한 시험 PC와 백업에서 실측하며 개인키·암호·계정·개인 경로·네트워크 주소·원본 로그를
공개 이슈에 올리지 마세요. 준비 문서를 검증·배포 완료 증거로 해석하지 않습니다.
