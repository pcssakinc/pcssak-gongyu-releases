# PCssak Gongyu 0.2.2 — 무료 Early Access

0.2.2는 SSH 방화벽 규칙의 실행 대상 판별과 오류 진단, 0.2.1에서 업데이트하는 설치
전이를 개선하는 패치입니다. 제보 사진에는 최종 실패 상세가 없어 해당 PC의 원인을
확정하지 않았습니다. 재현한 코드 결함의 수정과 실제 사용자 PC의 접속 성공은 구분합니다.

## SSH 방화벽 실행 대상 판별

- Windows의 기본 규칙 조회에서 패키지 정보가 비어 있거나 읽히지 않아도, 고유 규칙과
  전체 대응 조건·개수·활성 상태가 정확히 맞는 별도 정책 조회로 패키지 전용임을 확인하면
  시스템 OpenSSH와 무관한 규칙으로 구분합니다. 신규 변경 계획과 최종 상태 확인에 같은
  판별을 적용하여 관련 없는 앱 규칙 때문에 SSH 준비가 중단되는 경로를 보완했습니다.
- Xbox·Teams 등 표시 이름으로 예외를 만들지 않습니다. 대응이 없거나 일반 규칙이 섞여
  모호한 경우, 정책을 읽거나 증명할 수 없는 경우에는 안전 확인을 생략하지 않습니다.
- `LocalSubnet` 같은 별칭과 IPv4·IPv6 단일 호스트 주소가 섞인 목록도 항목별로 비교합니다.
  같은 주소의 `/32`·`/128` 표현 차이는 인정하지만 다른 주소나 더 넓은 범위는 허용하지 않습니다.
- 정상 복구 기록과 원래 꺼져 있던 규칙의 상태를 보존합니다. 불명확한 과거 기록을
  임의로 지우거나 다른 규칙에 배정하지 않습니다. 조회에 나타나지 않는 AppContainer
  격리 규칙과 조직 정책까지 자동으로 해소한다고 보장하지 않습니다.

## SSH 오류 진단

- 기존 안전 안내를 유지하면서 `SSH-FW` 진단 코드를 함께 표시합니다. Windows 정책 공급자
  연결·조회, 정책 읽기, 규칙 대응, 외부 정책 변경, 적용과 적용 후 확인을 구분합니다.
- 원시 규칙명·계정·개인 경로는 화면 진단 코드에 포함하지 않습니다. 확인된 고정 범주와
  8자리 Windows 오류 코드만 표시하며 모르는 상세는 임의로 해석하지 않습니다.
- 오류 메시지를 숨기거나 작업을 성공으로 표시하는 방식은 사용하지 않습니다.

## 설치와 앱 내 업데이트

- 설치 파일은 `PCssak-Gongyu-0.2.2-Windows-x64-Setup.exe`입니다.
- 법률 정본과 업데이트 공개키를 바꾸지 않습니다. 정상 법률 동의 기록이 남은 0.2.1 사용자는
  앱에서 새 버전을 확인하고 다운로드·서명 검증·사용자 승인 후 업데이트할 수 있습니다.
- 정상 법률 동의 기록이 있는 0.2.0도 동일한 검증·사용자 승인 절차로 앱 내 업데이트할 수 있습니다.
- 0.1.9는 현행 법률 문서 확인을 위해 공식 설치본을 직접 실행합니다. 0.1.8 이하는 앞서
  고지한 업데이트 공개키 전환 때문에 공식 설치본을 한 번 직접 실행해야 합니다.
- 0.1.1~0.2.1은 먼저 제거하지 않습니다. 새 설치기가 기존 앱 파일을 보호 교체하며 사용자
  설정·법률 동의·공유 장부·SSH 복구 기록을 보존합니다. 0.2.1 허용 누락을 이전 파일 백업,
  중단된 설치 복구, 대화형 교체, 재설치의 네 진입 분기에서 수정했습니다.
- 0.1.0에는 앱 내 업데이트가 없으므로 공식 설치본을 한 번 수동 설치해야 합니다.
- 이미 제거했다면 새 공식 설치본을 사용하되 Windows 복구 기록을 임의로 지우지 마세요.
  앱 교체와 SSH 초기화는 다릅니다. 0.1.0만 별도 수동 제거 후 설치 대상이며, 새 동의가
  필요하거나 설치 기록이 손상됐다면 대화형 설치로 안내합니다.

## 안전·지원 및 검증 범위

공개 설치본은 Windows x64 전용입니다. SSH는 신뢰하는 같은 물리 LAN용이며 VPN·가상
어댑터를 신뢰 범위에서 제외합니다. 관리자 권한과 공용 물리 LAN 신뢰의 필요한 동의를
유지합니다. 카페·호텔·공항·게스트 Wi-Fi를 신뢰 LAN으로 전환하지 마세요.

기존 OpenSSH를 재사용합니다. 켜기는 서비스 실행·자동 시작을 함께 확인하고, 끄기는
서비스 중지·사용 안 함 시작 유형·보호 규칙을 확인합니다. 완전 원복은 별도 기능이며
앱이 직접 설치한 소유 증거가 있는 OpenSSH만 제거 대상입니다. 사용자 설정·외부 규칙을
일괄 삭제하거나 방화벽·보안 제품·조직 정책을 해제하는 방식은 사용하지 않습니다.

Windows Authenticode 게시자 서명이 없습니다. Tauri 업데이트 서명·독립 Minisign 서명·
SHA-256은 무결성을 검증하지만 Windows 게시자 신뢰를 대신하지 않습니다. Windows나
보안 제품이 실행을 막을 수 있습니다. 보안 프로그램을 끄지 마세요. 해시·서명이 다르면
실행하지 마세요.

관리자 승인으로 `0.1.2 <= 버전 <= 0.4.9`는 무료 공개 Early Access로 제공합니다.
생산 계산 회귀와 실제 NSIS 엔진의 합성 분기 시험은 실제 제품 설치·SSH 접속 시험이 아닙니다.
최종 동결 소스의 Windows 로컬 14단계, 같은 소스의 빌드와 두 업데이트 서명, 법률 정본·
MPL 원본·정확한 불변 9자산 검증을 공개 전에 별도로 결속합니다.

- Windows 10/11 Home·Pro 전체 실기 검증이 완료되지 않았습니다.
- 실제 두 PC의 SSH/SFTP 실기 검증이 완료되지 않았습니다.
- 외부 법률 검토가 완료되지 않았습니다.
- 독립 공급망 검토가 완료되지 않았습니다.
- 실제 사용자 PC의 설치·일반 제거·공유 연결·SSH 로그인·SFTP·재부팅 지속성은 배포 후 확인합니다.

복구 가능한 시험 PC에서 최신 백업과 함께 사용하세요. 조직 정책, 설치 원본 부재,
다른 서비스의 포트 점유, 계정 인증 실패까지 항상 자동 해결한다고 보장하지 않습니다.
제보 사진과 다른 PC의 환경을 같다고 추정하거나 미실행 시험을 통과로 표시하지 않습니다.
