# PCssak Gongyu 0.2.3 — 무료 Early Access

0.2.3은 중단된 작업의 복구 안내가 숨겨진 카드로 연결되는 결함과, SSH 켜기 준비의
느린 조회가 무반응처럼 보이는 경로를 개선하는 패치입니다. 화면·메모리 재현과 코드
수정을 실제 사용자 PC의 복구·접속 성공과 구분하며, 오류 표시나 안전 검증을 삭제하지 않습니다.

## 중단된 작업의 복구 화면

- SSH 중단에도 설정의 확인 카드를 숨기지 않습니다. 자동설정의 중단 오류에서 이동한
  화면에 실제 상태와 다음 행동을 표시하고, 같은 종류의 SSH 켜기·끄기·완전 원복 재개
  버튼을 제공합니다. SSH 문제를 공유 자동설정으로 대신 해제하지 않습니다.
- 중단 상태를 읽는 동안과 읽기 실패·응답 지연에도 안내와 재조회 경로를 유지합니다.
  상태를 읽지 못한 것을 중단 기록 없음이나 복구 완료로 간주하지 않습니다.
- 수동 확인이 필요한 작업과 동일 작업 재개를 구분합니다. 사용자가 확인하지 않은
  복구 기록을 삭제하거나, SSH·공유 장부를 초기화하여 보호 차단을 우회하지 않습니다.

## SSH 켜기 준비와 응답성

- 켜기 버튼을 누르면 즉시 준비 상태를 표시하고 중복 입력을 막습니다. 준비 중 취소할 수
  있으며 취소·다른 작업·앱 잠금 뒤 도착한 오래된 준비 응답으로 SSH를 켜지 않습니다.
- 동의용 조회는 현재 물리 LAN의 안전 판별·공용 여부·정확한 네트워크 GUID·표시 이름과
  고정 진단만 읽습니다. 전체 서비스·방화벽 상태 조회를 동의 준비의 선행 조건으로
  기다리지 않습니다. 이전 화면의 네트워크 캐시는 새 동의에 사용하지 않습니다.
- 읽기 응답 상한은 동의 준비 15초·전체 SSH 상태 30초이고, 화면의 변경 전 준비 대기는
  20초입니다. 이는 설치·서비스·방화벽 변경의 제한 시간이 아닙니다. Windows 읽기가
  계속되고 있으면 응답 대기 종료 뒤에도 단일 실행권을 보존해 같은 조회가 쌓이지 않게 합니다.
- Windows 관리자 승인 창으로 인계한 뒤에는 준비 취소로 관리자 재실행까지 취소했다고
  표시하지 않습니다. 새 관리자 인스턴스는 현재 물리망과 사용자의 동의를 다시 확인합니다.
- 실제 켜기 직전과 적용 중·완료 후의 네트워크 GUID·정책·서버 신원·소유권·장부·원복
  검증은 그대로 유지합니다. 준비 조회 성공을 방화벽 안전 또는 SSH 로그인 성공으로
  표시하지 않으며, 읽기 지연을 Windows 변경 성공이나 강제 취소로 해석하지 않습니다.

## 기존 SSH·공유 보호 유지

- 0.2.2의 패키지 전용 방화벽 규칙 판별·동일 주소 표현 비교·개인정보를 제외한 SSH-FW
  진단을 유지합니다. 앱 표시 이름으로 예외를 만들거나 일반 위험 규칙을 무시하지 않습니다.
- LocalSubnet 등 별칭과 IPv4/IPv6 호스트 표현의 동등성만 인정하며 더 넓은 주소 범위는
  허용하지 않습니다. 모호한 원본·정책 조회 제한·외부 정책 변경은 계속 안전하게 중단합니다.
- SSH 켜기는 공유 자동설정과 독립된 사용자 선택입니다. 공유 전용 계정의 SSH/SFTP 차단,
  정확한 공유 소유권·권한·복구 기록을 보존합니다. 공유 준비만으로 SSH를 자동 활성화하지 않습니다.

## 설치와 앱 내 업데이트

- 설치 파일은 `PCssak-Gongyu-0.2.3-Windows-x64-Setup.exe`입니다.
- 법률 정본과 업데이트 공개키를 바꾸지 않습니다. 정상 법률 동의 기록이 남은 0.2.2 사용자는
  앱에서 새 버전을 확인하고 다운로드·서명 검증·사용자 승인 후 업데이트할 수 있습니다.
- 정상 법률 동의 기록이 있는 0.2.0·0.2.1도 동일한 검증·사용자 승인 절차로 앱 내 업데이트할 수 있습니다.
- 0.1.9는 현행 법률 문서 확인을 위해 공식 설치본을 직접 실행합니다. 0.1.8 이하는 앞서
  고지한 업데이트 공개키 전환 때문에 공식 설치본을 한 번 직접 실행해야 합니다.
- 0.1.1~0.2.2는 먼저 제거하지 않습니다. 새 설치기가 기존 앱 파일을 보호 교체하며 사용자
  설정·법률 동의·공유 장부·SSH 복구 기록을 보존합니다. 0.2.2 허용 누락을 이전 파일 백업,
  중단된 설치 복구, 대화형 교체, 재설치의 네 진입 분기에서 보완합니다.
- 0.1.0에는 앱 내 업데이트가 없으므로 공식 설치본을 한 번 수동 설치해야 합니다.
- 이미 제거했다면 새 공식 설치본을 사용하되 Windows 복구 기록을 임의로 지우지 마세요.
  앱 교체와 SSH 초기화는 다릅니다. 0.1.0만 별도 수동 제거 후 설치 대상이며, 새 동의가
  필요하거나 설치 기록이 손상됐다면 대화형 설치로 안내합니다.

## 안전·지원 및 검증 범위

공개 설치본은 Windows x64 전용입니다. SSH는 신뢰하는 같은 물리 LAN용이며 VPN·가상
어댑터를 신뢰 범위에서 제외합니다. 관리자 권한과 공용 물리 LAN 신뢰의 필요한 동의를
유지합니다. 카페·호텔·공항·게스트 Wi-Fi를 신뢰 LAN으로 전환하지 마세요.

기존 OpenSSH를 재사용합니다. 켜기는 서비스 실행·자동 시작을 함께 확인하고, 끄기는
서비스 중지·사용 안 함 시작 유형·보호 규칙을 확인합니다. 완전 원복은 별도 기능이며
앱이 직접 설치한 소유 증거가 있는 OpenSSH만 제거 대상입니다. 사용자 설정·외부 규칙을
일괄 삭제하거나 방화벽·보안 제품·조직 정책을 해제하는 방식은 사용하지 않습니다.

Windows Authenticode 게시자 서명이 없습니다. Tauri 업데이트 서명·독립 Minisign 서명·
SHA-256은 무결성을 검증하지만 Windows 게시자 신뢰를 대신하지 않습니다. Windows나
보안 제품이 실행을 막을 수 있습니다. 보안 프로그램을 끄지 마세요. 해시·서명이 다르면
실행하지 마세요.

관리자 승인으로 `0.1.2 <= 버전 <= 0.4.9`는 무료 공개 Early Access로 제공합니다.
생산 화면·메모리 회귀와 실제 NSIS 엔진의 합성 분기 시험은 실제 제품 설치·SSH 접속 시험이 아닙니다.
최종 동결 소스의 Windows 로컬 14단계, 같은 소스의 빌드와 두 업데이트 서명, 법률 정본·
MPL 원본·정확한 불변 9자산 검증을 공개 전에 별도로 결속합니다.

- Windows 10/11 Home·Pro 전체 실기 검증이 완료되지 않았습니다.
- 실제 두 PC의 SSH/SFTP 실기 검증이 완료되지 않았습니다.
- 외부 법률 검토가 완료되지 않았습니다.
- 독립 공급망 검토가 완료되지 않았습니다.
- 실제 사용자 PC의 설치·일반 제거·공유 연결·SSH 로그인·SFTP·재부팅 지속성은 배포 후 확인합니다.

복구 가능한 시험 PC에서 최신 백업과 함께 사용하세요. 조직 정책, 설치 원본 부재,
다른 서비스의 포트 점유, 계정 인증 실패까지 항상 자동 해결한다고 보장하지 않습니다.
제보 사진과 다른 PC의 환경을 같다고 추정하거나 미실행 시험을 통과로 표시하지 않습니다.
