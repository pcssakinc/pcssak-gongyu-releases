## 실행한 검사

같은 소스로 Windows 필수 14단계를 통과했습니다. Rust x64·i686 각각 1006개 통과·실패 0개·
수동 제외 23개, 화면 449개 통과이며 양쪽 Clippy 경고는 0입니다. 보안 감사는 기존에 기록된

제3자 고지·MPL 원본·릴리스 계약 검사도 포함합니다. GitHub Actions를 성공으로 표시한 것이
아니며 무료 Early Access의 승인된 로컬 Windows 검증 절차를 사용했습니다.

설치본의 Tauri 서명과 별도 업데이트 문서의 Minisign 서명을 확인했습니다. 공개 후에는
인증 없이 9개 파일을 다시 내려받아 크기·해시·서명 2개·스키마 3개·소스/법률/노트·MPL 원본
5개를 확인했습니다. 버전 태그, 최신 API, 최신 다운로드 별칭도 일치했습니다.

## 별도로 남긴 확인 범위

홈페이지 운영 반영과 두 도메인 검증은 별도 마감 결과로 기록합니다.

게시 뒤 사용자가 켜기 성공과 끄기 후 「꺼짐」 상태를 보고했습니다. 로그에서도 서비스
중지·자동 시작 차단은 성공했지만 과거 외부 규칙 복구가 실패한 것을 확인했습니다. 이 실패를
끄기 전체 실패처럼 안내하는 문제와, 완전 원복의 `SSH-FW/IDENTITY-MATCH-TARGET` 오류가
확인돼 **0.3.6 개선 대상으로 기록**했습니다. 0.3.5에서 해결됐다고 표시하지 않습니다.
사용자 지시에 따라 추가 앱 수정·0.3.6 배포 없이 이번 배포를 마감하며, 불변 0.3.5 파일과
기존 노트를 교체하지 않습니다.

위 제보·로그 읽기와 별개로 에이전트가 직접 수행하는 실제 설치·업데이트·제거,
SSH 켜기·끄기·복구, 실제 방화벽 규칙 등록과
패킷 차단, 두 PC의 로그인·SFTP·공유·재부팅은 **NOT_RUN**입니다. 자동 검사 통과만으로
모든 Windows 환경의 접속 성공이나 보안을 보장하지 않습니다.

설치본과 내부 실행 파일에는 Windows Authenticode 게시자 서명이 없습니다. 두 업데이트
서명은 게시자 신원을 대신하지 않습니다. Windows Home·Pro 전체 실기, 외부 법률·독립 공급망
검토의 미완료 고지를 유지합니다. 복구 가능한 시험 PC에서 백업과 보안 제품을 유지하며
확인해 주세요. 실패 시 방화벽 초기화나 기록 삭제로 우회하지 말고 진단 코드를 보존해 주세요.
