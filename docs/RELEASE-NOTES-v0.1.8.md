# PCssak Gongyu 0.1.8 — 무료 Early Access

0.1.8은 SSH 중단 복구와 여유 있는 화면 구성을 개선하는 긴급 패치입니다.
실제 제공 여부는 [버전 고정 릴리스](https://github.com/pcssakinc/pcssak-gongyu-releases/releases/tag/v0.1.8)의
검증된 자산으로 확인합니다. 이 설명만으로 게시 또는 모든 환경의 실측 완료를 뜻하지 않습니다.

## 주요 변경

- 기존 방화벽 규칙의 원래 속성과 개수가 정확히 일치하고 활성 상태만 바뀐 경우, 프로그램이
  보호 차단 아래에서 다시 조정합니다. 규칙을 중복 등록하거나 원래 복원 기준선을 덮어쓰지 않습니다.
- 중단된 SSH 켜기·끄기·완전 원복은 해당 버튼을 다시 눌러 이어갑니다. 실패한 켜기는 끄기로도
  안전하게 정리할 수 있습니다. 설정에서 기록을 수동으로 삭제하거나 확인 해제할 필요가 없습니다.
- SSH 복구 중에도 원래 작업 기록을 보존하며 최종 검증에 성공한 경우에만 완료 처리합니다.
  다른 프로그램이 계속 설정을 되돌리거나 규칙 신원·정책을 확인할 수 없으면 보호 차단을 유지합니다.
- 중단 기록 때문에 수리 버전 자체를 설치할 수 없던 흐름을 개선했습니다. 실제 실행 중인 작업은
  계속 차단하되, 업데이트는 SSH·공유 설정과 중단 기록을 그대로 보존합니다. 설치가 시스템 설정을
  수리한 것처럼 표시하지 않으며, 새 앱의 해당 기능에서 복구를 이어갑니다.
- 머신 작업 중단과 사용자 기록 손상이 함께 있을 때 복구 안내 순서를 바로잡았습니다.
- 본문 글자, 일반 버튼·입력칸과 카드 간격을 키웠습니다. 작은 화면·높은 배율에서도 메뉴 이름과
  주요 동작이 잘리지 않도록 줄바꿈과 스크롤을 조정했습니다. 기본 창 크기는 유지합니다.
- 0.1.7에서 0.1.8로의 자동·직접 설치 및 중단 복구 분기를 추가했습니다. 기존 사용자 설정과
  잠금 기능은 보존하며, 이전 제거기를 먼저 실행하지 않습니다.

## 설치와 업데이트

설치 파일 이름은 `PCssak-Gongyu-0.1.8-Windows-x64-Setup.exe`입니다.
법률 정본과 업데이트 공개키는 변경하지 않습니다. 정상 동의 기록이 있는 이전 버전은 앱에서
업데이트할 수 있습니다. 단, 이미 중단 기록으로 막혀 있는 0.1.7 이하 앱의 설치 차단 코드는
원격으로 바꿀 수 없습니다. 해당 경우 공식 0.1.8 설치본을 한 번 직접 실행해 덮어 설치하세요.
기존 앱을 먼저 삭제하거나 중단 기록을 지울 필요는 없습니다. 이 개선은 0.1.8부터 적용됩니다.

0.1.0 덮어 설치는 지원하지 않습니다. 설치 손상·법률 동의 누락·보안 제품의 실행 차단은 별도
상황이며 설치 성공을 보장하지 않습니다. 시작 시 및 약 6시간 간격 업데이트 확인과 실제 버전
표시는 유지합니다. GitHub Actions 대신 승인된 실제 Windows 로컬 검증 경로를 사용합니다.
실행하지 않은 Actions를 성공으로 표시하지 않으며, 기존 공개 태그와 자산은 교체하지 않습니다.

## 기존 0.1.0 사용자

0.1.0 사용자는 구 버전을 제거한 뒤 이번 한 번 0.1.8 설치본을 직접 다운로드하여 설치하세요.
0.1.8 이후에는 앱 내 업데이트를 사용할 수 있습니다. 0.1.0 덮어 설치는 지원하지 않습니다.

## SSH와 보안 범위

SSH는 신뢰하는 같은 물리 LAN용입니다. VPN의 존재 자체로 막지 않지만 VPN·가상 어댑터는
신뢰 범위에서 제외하며 VPN 경유 SSH·인터넷 직접 노출을 지원한다고 표시하지 않습니다.
공용 물리 LAN의 신뢰 전환과 관리자 권한은 필요한 동의를 계속 요구합니다. 조직 정책을 우회하지 않습니다.

일반 끄기는 OpenSSH를 제거하지 않아 다음 켜기에서 재설치하지 않습니다. 완전 원복은 적용 전
상태를 복원하고 앱이 설치한 기능만 소유 증거에 따라 제거합니다. 끄기의 검증은 새 접속을 받는
서비스·방화벽 상태에 관한 것이며, 기존 SSH 세션 전체 종료를 별도로 보장하지 않습니다.
최초 설치 시간은 Windows Update·WSUS·조직 정책에 따라 달라지고 임의의 3분 제한을 두지 않습니다.

정확한 신원·개수·원래 값이 확인되지 않는 규칙, 손상된 작업 기록, SSH 외 작업의 불확실한
부분 변경을 무조건 삭제하거나 복구 성공으로 처리하지 않습니다. 구형 방화벽 저널에는 패키지
신원이 없어 패키지 이름만 보고 자동 제거하는 이관은 포함하지 않습니다.

Windows Authenticode 게시자 서명이 없습니다. Tauri 업데이트 서명·Minisign 서명·SHA-256은
파일 무결성을 검증하지만 Windows 게시자 신뢰를 대신하지 않습니다. Windows·보안 제품은
실행을 막을 수 있습니다. SmartScreen·Smart App Control·백신의 경고를 무시하거나 조직 정책을
우회하지 마세요. Defender·백신 등 보안 프로그램을 끄지 마세요.

## 미완료 실측 고지

`0.1.2 <= 버전 < 0.2.0`은 실측을 수집하는 무료 Early Access입니다.

- Windows 10/11 Home·Pro 전체 실기 검증이 완료되지 않았습니다.
- 실제 두 PC의 SSH/SFTP 실기 검증이 완료되지 않았습니다.
- 외부 법률 검토가 완료되지 않았습니다.
- 독립 공급망 검토가 완료되지 않았습니다.

복구 가능한 시험 PC에서 최신 백업과 함께 사용하세요. 자동 검사와 한 PC의 실측을 모든 PC의
설치·SSH 성공으로 확대하지 않습니다. 정확한 최종 소스 검증과 불변 9자산·두 업데이트 서명은
공개 전 필수이며, 전체 실측과 신뢰 게시자 서명은 0.2.0 정식 단계 전에 보완해야 합니다.
