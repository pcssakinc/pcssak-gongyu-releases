# 품질과 안전

이 문서는 PCssak Gongyu 0.1.0 무료 Early Access의 검증 방법과 안전 경계를 설명합니다.
결함이 전혀 없거나 모든 PC와 호환된다는 보증이 아닙니다.

[English](QUALITY-AND-SAFETY.md)

## 사용자가 지시하는 시스템 변경

PCssak Gongyu는 현재 사용자 권한으로 시작합니다. 읽기 전용 조회와 사용자 범위 기능을 위해
항상 관리자 권한으로 실행하지 않습니다. PC 전체 Windows 상태를 바꾸는 백엔드 작업은 관리자
토큰을 다시 확인하고 필요한 권한이 없으면 변경을 거부합니다.

앱은 다음 범위를 분리합니다.

- SMB 자동 설정과 기록된 원복 상태
- 사용자가 만든 공유·드라이브 매핑·저장 자격증명
- TCP 19763의 짧은 공유 페어링 세션
- 별도로 동의한 OpenSSH Server·`sshd`·TCP 22 설정

SMB 자동 설정은 SSH를 몰래 켜지 않습니다. 화면 공유·마우스 제어용 MSRA는 0.1.0에서
비활성화되며 SSH 원격 셸·명령 실행·SFTP와 같은 기능이 아닙니다.

## 소유권과 실패 폐쇄

공유 이름·경로·무작위 관리 토큰이 Windows 공유 설명과 머신 소유권 기록에서 모두 일치할 때만
PCSSAK 관리 공유로 인정합니다. 증거가 없는 외부·구버전 공유는 파괴적 관리 작업에서 읽기 전용으로
표시합니다.

Windows, Program Files, ProgramData, 드라이브 루트와 사용자 프로필 등 민감 경로는 관리 공유
해제와 페어링 ACL 변경에서 백엔드가 거부합니다. 화면 검증을 우회해도 백엔드 차단은 유지됩니다.

PC 전체 변경은 전역 단일 인스턴스 뮤텍스와 작업 저널을 사용합니다. 첫 앱이 실행 중이면 다른
Windows 사용자나 RDP 세션에서 두 번째 앱을 시작할 수 없습니다. 중단되거나 결과가 불확실한
작업은 미완료로 알리며 성공으로 표시하면 안 됩니다.

## 방화벽과 LAN 경계

자동 설정이 만드는 SMB·NetBIOS 규칙은 Domain·Private 프로필과 Windows `LocalSubnet`으로
제한합니다. 이름만 같고 원격 범위가 더 넓은 규칙은 안전한 결과로 인정하지 않습니다.

SSH는 별도 명시 동의 기능입니다. 0.1.0은 같은 공유기·같은 LAN에서 신뢰하는 물리 Ethernet·
Wi-Fi에 연결되고 Private 또는 Domain 프로필을 사용하는 호스트 PC만 지원합니다. PCSSAK 소유
인바운드 규칙은 실제 Windows `System32\OpenSSH\sshd.exe`, TCP 22, Lan·Wireless 인터페이스와
SSH를 켠 순간의 정확한 로컬 IPv4·온링크 범위에 결속됩니다.

활성 Public 프로필, 주소가 있는 VPN·터널, 어댑터·방화벽 조회 실패가 하나라도 있으면 SSH 켜기를
차단합니다. VPN, 인터넷 직접 접속과 라우터 포트포워딩은 지원하지 않습니다. DHCP 주소나 물리
네트워크가 바뀌면 SSH를 끄고 새 LAN을 신뢰하는지 확인한 뒤 다시 켜야 합니다.

“로컬 준비 완료”는 호스트 서비스·방화벽 계약·로컬 리스너를 확인한 결과이며 실제 원격 로그인이나
SFTP 전송을 증명하지 않습니다. 같은 LAN 두 PC의 실기와 별도 경로로 확인한 서버 호스트 키 지문이
필요합니다.

## 페어링과 자격증명

공유 페어링은 8자리·5분·1회용 코드를 사용합니다. 현재 프로토콜은 RFC 9807 OPAQUE와 Argon2id를
사용하고 인증 뒤 OPAQUE 세션 키에서 파생한 AES-256-GCM 보호 응답으로만 SMB 자격증명을
전달합니다. 코드 원문과 단순 해시는 로그나 TCP 19763으로 보내지 않습니다. 속도 제한은 온라인
추측 위험을 줄이지만 짧은 코드를 공개해도 안전하게 만들지는 않습니다.

저장한 SMB 비밀번호는 Windows DPAPI 현재 사용자 범위로 보호합니다. 사용자는 Windows 자격 증명
관리자 저장을 별도로 선택할 수 있습니다. 비밀번호·페어링 코드·개인키를 공개 Issue나 전체 로그에
포함하지 마세요.

## 원복과 제거

앱은 Windows 상태를 바꾸기 전에 지원 원복에 필요한 증거를 기록합니다. 원복은 소유권과 변경 전
기록이 확인한 항목만 바꾸며 알 수 없는 공유·규칙·계정을 앱 소유로 추정하지 않습니다.

일반 원복과 NSIS 제거는 사용자가 만든 모든 공유·매핑·자격증명·로컬 앱 데이터·자동 시작·별도로
켠 OpenSSH/SSH를 자동 삭제하지 않습니다. 제거 전에 앱 상태와
[알려진 한계](KNOWN-LIMITATIONS.ko.md)를 확인하세요. 원복이 실패하면 복구 도구가 먼저 지워지지
않도록 제거가 중단될 수 있습니다.

## 로컬 우선 개인정보 경계

앱에는 PCSSAK 텔레메트리, 광고, 온라인 계정, 자동 오류 업로드, 라이선스 서버 또는 자동
업데이트가 없습니다. 로컬 파일·경로·네트워크 식별자·설정·저널·로그를 PCSSAK으로 자동 업로드하지
않습니다.

로컬 우선이 오프라인 전용이라는 뜻은 아닙니다. 사용자가 요청한 LAN·SMB·Wake-on-LAN·페어링·
SSH는 선택한 네트워크 장치와 통신합니다. OpenSSH Server 설치는 Windows Update·WSUS 또는
조직이 정한 원본과 통신할 수 있습니다. [개인정보 처리방침](../PRIVACY.md)을 확인하세요.

## 릴리스 무결성

첫 공개 빌드는 x64 NSIS 설치 파일 하나입니다. Authenticode 서명이 없고 자동 업데이트 모듈이
없으므로 Tauri 업데이트 서명도 없습니다. Windows에 알 수 없는 게시자나 SmartScreen이 나타날
수 있으며 사용자는 Windows 보안 제품을 끄면 안 됩니다.

버전 고정 `v0.1.0` 릴리스는 [릴리스 자산 계약](RELEASE-ASSET-CONTRACT.md)의 다섯 자산만
포함해야 합니다. `SHA256SUMS.txt`는 자신을 제외한 모든 다운로드 자산을 포함하며 정확한
MPL-2.0 원본 묶음을 설치 파일과 함께 제공합니다. `latest.json`은 다운로드 메타데이터이지
서명된 자동 업데이트 매니페스트가 아닙니다.

## 검증 계층

0.1.0 소스에서 릴리스 자산 조립 전에 다음 로컬 자동 검증 기록을 남겼습니다.

- x64·i686 각 대상에서 실행된 Rust 시험 425개 통과, 일반 묶음의 수동 Argon2 하네스 1개 제외
- x64·i686 엄격 Clippy 경고 0
- 네트워크 모듈 반복 시험 1,180개 통과
- UI 시험 57개 통과
- 앱 10개 언어 각 959키 일치
- 정적 사전점검 10/10 통과
- `cargo audit` 알려진 취약점 0, 근거를 기록한 유지보수 중단 경고 12개
- Windows 의존성 제3자 고지 285개 항목 생성
- 공개 릴리스 템플릿·아이콘 프레임·결정적 MPL 원본 묶음 시험 통과

이 결과는 최종 설치 파일과 같은 바이트에 대한 실제 설치·승격·재부팅·원복·업데이트·제거·백신·
동일 LAN 두 PC 시험을 대신하지 않습니다. GitHub Actions 포함 시간 소진으로 준비한 소스·배포
PR의 러너가 시작되지 않았으며, 러너 시작 전 실패를 CI 통과로 표시하지 않습니다.

PCSSAK은 이 실기 공백을 공개 고지하는 조건으로 0.1.0 무료 Early Access 배포를 승인했습니다.
미완료 증거는 검증 통과가 아니라 알려진 한계로 유지합니다. 재현 가능한 결함은 고정된 v0.1.0
자산을 교체하지 않고 새 0.1.1 이상 릴리스에서 우선순위를 정해 수정합니다.

## 호환성 주장

Windows 11 Home/Pro x64와 Windows 10 22H2 Home/Pro x64는 0.1.0 검증 목표입니다. 모든
후보에서 실기가 끝났다는 뜻이 아닙니다. Windows 10 일반 지원은 종료됐으므로 ESU·LTSC 상태는
사용자가 별도로 확인해야 합니다. ARM64 네이티브, Windows S 모드, Windows Server, macOS와
Linux는 지원 배포 대상이 아닙니다. x86 컴파일·시험 결과는 공개 x86 설치 파일 지원 선언이
아닙니다.

정확한 설치 파일 해시와 완료한 환경을 식별한 릴리스 기록만 해당 버전의 실기 증거로 사용합니다.

## 사용자가 지킬 사항

- 공식 PCSSAK 버전 고정 릴리스 또는 제품 페이지에서만 내려받습니다.
- 설치 파일 SHA-256을 `SHA256SUMS.txt`와 비교합니다.
- SmartScreen, Microsoft Defender와 방화벽을 끄지 않습니다.
- 민감하지 않은 시험 폴더부터 시작하고 별도 백업을 유지합니다.
- 관리 권한을 가진 시스템·네트워크에서만 공유와 SSH를 사용합니다.
- SSH를 신뢰하기 전에 다른 PC에서 호스트 키 지문과 실제 로그인을 확인합니다.
- 지원 요청 전에 개인정보·자격증명·네트워크 정보를 제거합니다.

일반 오류는 구조화된 Issue 양식을 사용하고 악용 가능한 보안 문제는 [SECURITY.md](../SECURITY.md)에
따라 비공개로 제보하세요.
