# PCssak Gongyu 0.1.5 설치 수정 안내

이 문서는 무료 Early Access `0.1.5`의 공개 준비 안내입니다. 설치본이 게시됐다는 증거는
아니며 실제 공개 여부와 승인된 최종 노트는 [버전 고정 릴리스](https://github.com/pcssakinc/pcssak-gongyu-releases/releases/tag/v0.1.5)를
기준으로 합니다. 같은 태그의 기존 자산은 교체하지 않습니다.

## 설치 준비 중단 수정

0.1.4의 기존 설치 폴더 준비 과정에서 Windows 오류를 즉시 회수하지 않아 정상적으로 이미
존재하는 폴더를 설치 실패로 잘못 판단하는 결함을 확인했습니다. 0.1.5는 NSIS의
`CreateDirectoryW` 호출 직후 `?e`로 오류를 보관하고 `Pop`으로 회수하여 해당 결과와 결속합니다.
폴더·소유권·권한·설치 파일 검증을 생략해 통과시키는 수정이 아닙니다.

이 문제로 0.1.4 업데이트가 중단됐다는 보고 뒤 최신 배포 지정을 0.1.3으로 되돌려 추가
0.1.4 안내를 중지했습니다. 이전 0.1.4 불변 자산을 수정하지 않고 더 높은 0.1.5로 준비합니다.
사용자가 이전 버전을 차례로 먼저 설치해야 해결되는 문제로 안내하지 않습니다.

## 설치와 앱 내 업데이트

- 공개 설치 파일명은 `PCssak-Gongyu-0.1.5-Windows-x64-Setup.exe`입니다.
- 0.1.0에는 앱 내 업데이트가 없어 공식 설치본을 한 번 수동 설치해야 합니다.
- 0.1.1은 변경된 법률 문서에 새 동의가 필요할 수 있습니다. 유효한 법률 동의 기록이 남은
  0.1.3·0.1.4 사용자는 앱 내 새 버전 확인·다운로드·서명 검증·사용자 승인 경로를 사용합니다.
- 법률 정본·업데이트 공개키·설정 보존 계약은 그대로입니다. 실제 전체 설치·업데이트 행렬은
  아직 미완료이며 공개 파일 검증을 실제 설치 성공으로 바꿔 주장하지 않습니다.

## Windows 보안 차단과의 구분

이번 폴더 준비 오류는 Windows 11 Smart App Control(SAC) 또는 보안 제품의 실행 차단과
다릅니다. Authenticode 게시자 서명은 아직 제공하지 않으며 Tauri/Minisign 업데이트 무결성
서명이 이를 대신하지 않습니다. 앱은 SAC·Defender·SmartScreen·방화벽·조직 정책을 자동
해제하거나 우회하지 않습니다. 설치·실행이 SAC에 차단되면 보호 기능을 유지한 채 시험을
보류하세요.

재활성화 조건을 모든 Windows 환경에서 동일하게 가정하거나 끄고 바로 켜면 된다고 약속하지
않습니다. 최신 Microsoft 공식 근거와 구분은 [보안 정책](../SECURITY.md)에 정리했습니다.

무서명 제거기만 SAC에 차단되어 사용자가 직접 제거를 선택하면, 해당 Windows 환경에서
초기화 없이 재활성화할 수 있음이 사전 확인된 개인 PC에 한해 SAC 일시 중지 → 공식 제거 →
즉시 재활성화 및 켜짐 확인을 선택할 수 있습니다. 불명확·초기화/재설치 필요·조직 관리
환경에서는 SAC 중지를 안내하지 않습니다. Defender·SmartScreen·방화벽 해제나 앱의 자동
보안 변경은 포함되지 않습니다. 자세한 사전 조건과 복구 확인은 위 보안 정책을 따르세요.

## 무료 Early Access의 미완료 범위

- Windows 10/11 Home·Pro x64 전체 실제 설치·업데이트·복구·제거 행렬: 미완료.
- 실제 두 PC SSH/SFTP·끄기·재설치 없는 재켜기·완전 원복·VPN 공존 행렬: 미완료.
- Authenticode 게시자 서명·외부 법률 검토·독립 공급망 검토: 미완료.
- 최종 소스 Actions·양 업데이트 서명·정확한 9자산·SHA-256 검증은 공개 전 필수이며
  이 준비 문서는 그 완료 증거가 아닙니다. 0.2.0 전에 정식 게이트를 복원합니다.

복구 가능한 시험 PC와 백업에서 실측하며 설치를 위해 보안 기능을 끄지 않습니다. 개인키·암호·실제 계정·
네트워크 주소·개인 경로·원본 로그를 공개 이슈에 올리지 마세요.
