# PCssak Gongyu 0.2.0 — 무료 Early Access

0.2.0은 SSH 켜기·끄기의 상태 확인, 설정 적용 보호, 일반 제거의 부분 삭제 방지와
이전 버전의 안전한 교체를 개선합니다. 0.1.9의 방화벽 비교·개인/팀 공유·관리자 재개·중단
복구 개선도 함께 포함합니다. 실제 제공 여부는
[버전 고정 공식 릴리스](https://github.com/pcssakinc/pcssak-gongyu-releases/releases/tag/v0.2.0)의
검증된 자산으로 확인합니다. 이 문서만으로 모든 PC의 실측 완료를 뜻하지 않습니다.

## 설치와 업데이트

- 설치 파일은 `PCssak-Gongyu-0.2.0-Windows-x64-Setup.exe`입니다.
- 이번에는 무료 공개 범위가 0.4.9까지 확대되어 동봉 사용권 계약과 개인정보 처리방침의
  적용 범위·시행일이 바뀝니다. 0.1.9 사용자는 앱에서 새 버전을 확인한 뒤 공식 다운로드로
  이동하여 새 문서를 확인하고 설치합니다. 새 동의가 필요한 업데이트를 무인 설치하지 않습니다.
- 0.1.8 이하 앱에는 현행 업데이트 공개키가 없으므로 공식 설치본을 한 번 직접 실행해야 합니다.
  구형 앱의 서명 오류를 우회하지 말고 공식 홈페이지 또는 버전 고정 릴리스를 이용하세요.
- 0.1.1~0.1.9는 기존 앱을 먼저 제거하거나 사용자 설정·공유 장부·SSH 설정·중단 기록을
  지우지 않고 덮어 설치합니다. 앱이 새 파일과 기존 파일의 보호 교체를 진행합니다.
- 0.1.0은 덮어 설치 지원 대상이 아닙니다. 구 버전을 제거한 뒤 공식 설치본을 직접 설치하세요.
- 같은 법률 정본과 동의 기록을 확인할 수 있는 후속 업데이트는 앱에서 다운로드·무결성 확인·
  사용자 승인 후 적용합니다. 이후 정본이 바뀌면 다시 대화형 설치로 안내합니다.

현재 앱의 사용자 설정은 업데이트 교체 대상이 아닙니다. 기존 앱과 제거기가 이미 일부
사라진 손상 설치, 조직의 실행 차단, 파일 잠금이 해제되지 않는 환경까지 설치 성공을 보장하지
않습니다. 다른 버전의 파일을 섞거나 복구 기록을 임의로 삭제하지 마세요.

## SSH 켜기·끄기와 설정 보호

- 실행 중이라는 이유만으로 켜기 완료를 반환하지 않습니다. 자동 시작 설정까지 확인하고,
  수동·사용 안 함 상태라면 보호된 켜기 경로에서 자동 시작을 다시 설정·확인합니다.
- 화면의 로컬 준비 판정도 자동 시작을 확인합니다. 잘못된 준비 표시와 접속 안내를 줄였습니다.
- 현재 SSH 프로세스가 관리 설정을 적용했다는 증거가 없으면, 파일 내용이 같아도 보호 차단
  상태에서 재시작합니다. 기동 전후 설정 지문·프로세스·자동 시작을 다시 확인합니다.
- 켜기 중 관리 설정 파일의 일반 쓰기·삭제·교체를 막는 읽기 핸들을 유지하며, 최종 검증 뒤에
  보호 차단을 해제합니다. 설정의 Include 대상이나 외부 관리 도구의 모든 변경을 통제하는 것은 아닙니다.
- 일반 끄기는 서비스를 중지하고 시작 유형을 `Disabled`로 확인합니다. OpenSSH 기능은
  제거하지 않으므로 다시 켤 때 설치 단계를 반복하지 않습니다. 켜기는 `Auto`, 끄기는
  `Disabled`가 재부팅 뒤에도 적용되도록 구성하지만 이번 후보의 실제 재부팅 시험은 미실행입니다.
- 기존 방화벽 규칙은 의미가 같은 주소·마스크·목록 순서를 같은 그룹으로 비교합니다.
  다른 범위·프로필·프로그램은 합치지 않으며 원래 값 기록과 실패 시 복원 확인은 유지합니다.
- 완전 원복은 별도 동의 후 적용 전 상태를 복원하며, 앱이 설치했다는 소유 증거가 있는
  OpenSSH 기능만 제거합니다. 사용자가 원래 설치한 기능은 보존합니다.

## 구버전 교체와 일반 제거

- 0.1.9에서 새 버전으로 넘어오는 보호 백업·중단 복구·대화형 교체·재설치 경로를 추가했습니다.
- 일반 제거는 소유 파일 여섯 개를 모두 확보한 뒤에만 삭제를 예약·확정합니다. 다른 파일이
  잠겼는데 앱과 제거기부터 사라지던 문제를 보완했습니다. 잠금이 해제되면 다시 시도할 수 있습니다.
- 파일을 일부 지운 채 길게 반복 대기하는 일반 제거 경로를 없앴습니다. 업데이트 교체의
  보호 백업·유한 재시도·설정 보존은 유지합니다.
- 삭제 예약 취소 실패, 확정 후 잔존, 접근 거부 등으로 부재를 확인하지 못한 경우에는 제거
  성공 또는 원본 전체 보존으로 안내하지 않습니다. 예상과 다른 파일을 임의 삭제하지 않습니다.
- 앞서 사용자가 동의하여 완료한 회원 정리·Windows 원복은 이후 파일 잠금 오류로 되돌아가지
  않습니다. 안내에서 이 경계를 구분합니다. 강제 종료·전원 차단의 다중 파일 원자성과 이미
  손상된 구형 설치의 자동 복구를 이번 개선으로 보장하지 않습니다.

## 공유·회원·관리자 재개

- 자동 설정·원복·구버전 잔재 정리는 첫 조회부터 실행 상태를 공유하여 버튼 연속 클릭이나
  동의 토글로 중복 작업이 시작되지 않게 했습니다. 실패·취소 뒤에는 다시 실행할 수 있습니다.
- SSH 권한 조회 중 끄기를 완료한 경우 늦게 도착한 켜기 응답과 관리자 재실행을 폐기합니다.
- 연결 해제 후 계정 확인이 늦게 도착했을 때 앱이 잠기거나 목록이 바뀌면 이전 확인창과
  계정 삭제 요청을 폐기합니다. 저장 계정 삭제는 정상 화면에서도 별도 동의를 유지합니다.
- 개인·팀 공유 선택, 회원 요청 승인·폴더 권한, 필요한 SMB 서비스·방화벽 자동 준비를 유지합니다.
- 공용 물리 LAN은 사용자가 신뢰한 정확한 연결만 전환합니다. 조직 정책·불명확한 네트워크를
  우회하거나 전체 주소에 포트를 열지 않습니다.
- 관리자 재개는 일회용 암호화 입력과 원래 작업 대상을 확인합니다. UAC 취소 뒤 기존 초대나
  서비스·방화벽을 임의로 정리하지 않으며, 오래된 요청을 뒤늦게 실행하지 않도록 확인합니다.
- 공유·회원·권한의 복구는 원래 기록과 실제 대상을 결속합니다. 다른 회원 권한과 원본 폴더·파일은
  정리 대상이 아닙니다. 연결 해제와 저장된 연결 등록 해지는 구분합니다.

## 보안과 지원 범위

공개 설치본은 Windows x64 전용입니다. x86 컴파일·시험은 x86 공개 지원의 실기 증거가 아닙니다.
SSH는 신뢰하는 같은 물리 LAN용이며 VPN·가상 어댑터는 신뢰 범위에서 제외합니다.
VPN 경유 SSH·인터넷 직접 노출·포트 포워딩을 지원한다고 표시하지 않습니다. 공용 LAN 신뢰와
관리자 권한은 필요한 동의를 계속 요구합니다. 카페·호텔·공항·게스트 Wi-Fi에서 신뢰 전환에
동의하지 마세요. 최초 OpenSSH 설치 시간은 Windows Update·WSUS·조직 정책에 따라 달라집니다.

Windows Authenticode 게시자 서명이 없습니다. Tauri 업데이트 서명·Minisign 서명·SHA-256은
파일 무결성을 검증하지만 Windows 게시자 신뢰를 대신하지 않습니다. Windows·보안 제품은
실행을 막을 수 있습니다. 경고나 조직 정책을 무조건 우회하지 마세요. 보안 프로그램을 끄지 마세요.
실제 파일의 해시·서명이 다르면 실행하지 마세요.

## 배포 후 실측과 알려진 제한

관리자 승인으로 `0.1.2 <= 버전 <= 0.4.9`는 무료 공개 Early Access로 제공합니다.

- Windows 10/11 Home·Pro 전체 실기 검증이 완료되지 않았습니다.
- 실제 두 PC의 SSH/SFTP 실기 검증이 완료되지 않았습니다.
- 외부 법률 검토가 완료되지 않았습니다.
- 독립 공급망 검토가 완료되지 않았습니다.
- 실제 사용자 PC의 설치·일반 제거·공유 연결·SSH 로그인·SFTP·재부팅 지속성은 배포 후 확인합니다.

복구 가능한 시험 PC에서 최신 백업과 함께 사용하세요. 자동시험·컴파일·더미 파일을 사용하는
설치기 시험은 실제 제품 설치와 두 PC 접속 시험을 대신하지 않습니다. 최종 소스의 승인된
Windows 로컬 검증 또는 Actions, 불변 9자산·두 업데이트 서명·MPL 원본·법률 정본 결속은
공개 전에 확인합니다. 실행하지 않은 검사나 확인하지 않은 환경을 완료로 표시하지 않습니다.
