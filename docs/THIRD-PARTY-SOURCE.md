# MPL-2.0 구성요소 원본 소스 / MPL-2.0 Component Source

## 현재 0.2.1 안내 / Current 0.2.1 guidance

0.2.1의 정확한 MPL-2.0 원본 묶음은 같은 버전 고정 릴리스의
[`PCssak-Gongyu-0.2.1-MPL-Sources.zip`](https://github.com/pcssakinc/pcssak-gongyu-releases/releases/download/v0.2.1/PCssak-Gongyu-0.2.1-MPL-Sources.zip)입니다.
이 링크는 준비된 배포 계약이며, [`v0.2.1` 릴리스](https://github.com/pcssakinc/pcssak-gongyu-releases/releases/tag/v0.2.1)에
설치본과 정확한 9자산이 실제 게시되고 검증된 경우에만 공식 제공물입니다. 문서만으로 게시
완료를 뜻하지 않으며 아직 파일이 없으면 공개 원본 묶음이 제공된 상태가 아닙니다.

묶음은 최종 소스의 정확한 `Cargo.lock`과 Windows x64·i686 잠금 그래프로 생성합니다.
구성요소·버전·`.crate` SHA-256은 묶음 안 생성 매니페스트에 기록합니다. 같은 릴리스의
[`THIRD-PARTY-NOTICES.txt`](https://github.com/pcssakinc/pcssak-gongyu-releases/releases/download/v0.2.1/THIRD-PARTY-NOTICES.txt)와
대조하고 [`SHA256SUMS.txt`](https://github.com/pcssakinc/pcssak-gongyu-releases/releases/download/v0.2.1/SHA256SUMS.txt)로
원본 묶음의 해시를 확인하세요. 다른 버전의 원본이나 임의 저장소 ZIP으로 대체하지 않습니다.

The exact MPL-2.0 component source for 0.2.1 is
[`PCssak-Gongyu-0.2.1-MPL-Sources.zip`](https://github.com/pcssakinc/pcssak-gongyu-releases/releases/download/v0.2.1/PCssak-Gongyu-0.2.1-MPL-Sources.zip)
in the same [version-pinned release](https://github.com/pcssakinc/pcssak-gongyu-releases/releases/tag/v0.2.1).
This is the prepared distribution contract, not proof of publication. The archive is an official
asset only after that release publishes and verifies the installer and exact nine-asset set.
If the file is absent, the public source archive has not been provided yet.

The archive is generated from the final source's exact `Cargo.lock` and locked Windows x64/i686
graphs. Its generated manifest identifies each component, version, and `.crate` SHA-256. Cross-check
the same release's [`THIRD-PARTY-NOTICES.txt`](https://github.com/pcssakinc/pcssak-gongyu-releases/releases/download/v0.2.1/THIRD-PARTY-NOTICES.txt)
and verify the archive hash in [`SHA256SUMS.txt`](https://github.com/pcssakinc/pcssak-gongyu-releases/releases/download/v0.2.1/SHA256SUMS.txt).
Do not substitute a different version's sources or an arbitrary repository archive.

## 0.1.1 당시 이력 / Historical 0.1.1 guidance

아래 본문은 과거 버전 기록입니다. 현행 0.2.1의 다운로드·라이선스·지원 조건으로 해석하지
마세요. The following text is historical and does not define current 0.2.1 download, license,
or support conditions.

PCssak Gongyu 0.1.1은 수정하지 않은 MPL-2.0 적용 구성요소를 바이너리 형태로 포함합니다.
정확한 원본은 설치 파일과 같은 버전 고정 GitHub 릴리스의
[`PCssak-Gongyu-0.1.1-MPL-Sources.zip`](https://github.com/pcssakinc/pcssak-gongyu-releases/releases/download/v0.1.1/PCssak-Gongyu-0.1.1-MPL-Sources.zip)으로
제공합니다.

위 파일은 [`v0.1.1` 릴리스](https://github.com/pcssakinc/pcssak-gongyu-releases/releases/tag/v0.1.1)에
설치 파일과 정확한 9개 고정 자산 전체가 실제로 게시된 경우에만 공식 제공물입니다. 링크에
파일이 없으면 아직 공개된 원본 묶음도 없습니다.

원본 묶음 대상은 0.1.1의 정확한 `Cargo.lock`과 Windows x64·i686 잠금 그래프에서 결정하고,
구성요소·버전·`.crate` SHA-256은 묶음 안 생성 매니페스트에 기록합니다. 문서의 수동 목록이나
임의의 저장소 브랜치·태그 ZIP으로 바꾸지 않습니다. 같은 릴리스의
[`THIRD-PARTY-NOTICES.txt`](https://github.com/pcssakinc/pcssak-gongyu-releases/releases/download/v0.1.1/THIRD-PARTY-NOTICES.txt)와
교차 검증하며 `SHA256SUMS.txt`에서 원본 묶음 SHA-256을 확인하세요.

설치 프로그램은 전체 제3자 고지를 설치 경로의 `legal` 폴더에도 배치합니다. 링크가 작동하지
않거나 특정 MPL 구성요소의 원본 사본이 필요하면 제품 버전과 구성요소 이름만
`support@pcssak.com`으로 보내 주세요. 자격증명·개인 파일·로그는 필요하지 않습니다.

PCssak Gongyu 0.1.1 includes unmodified MPL-2.0-covered components in binary form. Their exact
source is provided with the installer in the same version-pinned GitHub release as
[`PCssak-Gongyu-0.1.1-MPL-Sources.zip`](https://github.com/pcssakinc/pcssak-gongyu-releases/releases/download/v0.1.1/PCssak-Gongyu-0.1.1-MPL-Sources.zip).

The file is an official distribution asset only when the
[`v0.1.1` release](https://github.com/pcssakinc/pcssak-gongyu-releases/releases/tag/v0.1.1)
actually publishes the installer and complete fixed asset set. If the asset is absent, no public
source bundle has been published yet. The complete set is exactly the nine files fixed by the
release asset contract.

The source-bundle set is derived from the exact 0.1.1 `Cargo.lock` and Windows x64 and i686 lock
graphs. The generated manifest inside the archive records each component, version, and `.crate`
SHA-256. It must not be replaced by a manually maintained list or an arbitrary repository branch
or tag archive. Cross-check it with
[`THIRD-PARTY-NOTICES.txt`](https://github.com/pcssakinc/pcssak-gongyu-releases/releases/download/v0.1.1/THIRD-PARTY-NOTICES.txt)
and verify the source archive SHA-256 in `SHA256SUMS.txt` from the same release.

The installer also places the complete third-party notice in its `legal` directory. If the source
link is unavailable or a particular MPL component copy is needed, email `support@pcssak.com` with
only the product version and component name. Credentials, personal files and logs are unnecessary.
